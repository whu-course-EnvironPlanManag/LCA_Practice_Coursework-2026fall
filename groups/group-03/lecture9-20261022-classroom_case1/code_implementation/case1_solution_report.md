# 案例一作业报告：PET 瓶机械物理再生 MFA-LCA-TEA

## 任务一：100% 绿电情景与收率敏感性

### 1. MFA 基准与质量守恒

以处理 1,000 kg 废 PET 瓶砖为批次基准，产品及输出为：

| 输出流 | 质量 (kg) |
| --- | ---: |
| 瓶级 rPET 主产品 | 800 |
| 回收 HDPE 副产品 | 75 |
| 标签与泥沙 | 45 |
| 洗涤杂质 | 35 |
| HDPE 夹带损失 | 5 |
| 杂色片与细粉 | 40 |
| **输出合计** | **1,000** |

因此，基准产品收率为 $800/1{,}000=80.0\%$，每吨 rPET 需要 $1/0.80=1.25$ t 瓶砖。上述质量平衡沿用给定 MFA 数据；清洗过程加入的水不在这张固体物料平衡表内。

### 2. 绿电情景 LCA

功能单位为出厂 1 t 瓶级 rPET。保持运输、蒸汽、药剂、水、污水处理和 HDPE 避免负荷信用不变，只将电力排放因子从 0.55 改为 0.03 kg CO₂e/kWh：

| 清单项目 | 活动水平 | 因子 | 排放贡献 (kg CO₂e/t rPET) |
| --- | ---: | ---: | ---: |
| 瓶砖运输 | 1,250 kg × 100 km | 0.12 kg CO₂e/(t·km)，按讲义清单结果 | 150.00 |
| 生产电力 | 850 kWh | 0.03 kg CO₂e/kWh | 25.50 |
| 天然气蒸汽 | 2.0 GJ | 65 kg CO₂e/GJ | 130.00 |
| NaOH | 15 kg | 2.10 kg CO₂e/kg | 31.50 |
| 新鲜水 | 2.5 m³ | 0.38 kg CO₂e/m³ | 0.95 |
| 污水处理 | 2.2 m³ | 2.75 kg CO₂e/m³ | 6.05 |
| HDPE 替代信用 | −93.75 kg | 1.60 kg CO₂e/kg | −150.00 |
| **净碳足迹** |  |  | **194.00** |

与电网基准情景相比，电力排放减少 $(0.55-0.03)\times850=442.0$ kg CO₂e/t；因此 $GWP_{green}=636.0-442.0=194.0$ kg CO₂e/t。相较原生 PET 基准，减排量为 $2{,}250-194=2{,}056$ kg CO₂e/t，减排率为 $2{,}056/2{,}250=91.4\%$。

### 3. 绿电情景 TEA 与定价建议

绿电电价为 $0.65+0.05=0.70$ 元/kWh，吨产品电费增加 $850\times0.05=42.50$ 元。因此：

- $LCOP_{green}=6{,}153.4+42.5=6{,}195.9$ 元/t；
- 成本增幅为 $42.5/6{,}153.4=0.69\%$；
- 按售价 7,600 元/t，吨产品税前毛利由 1,446.6 降至 1,404.1 元。

建议在供货合同中将至少 42.5 元/t 作为绿电成本传导的基准溢价，并用可核验的绿电采购凭证、产品碳足迹核查结果支持更高的客户绿色溢价谈判。溢价高于成本补偿部分属于市场策略，不在本案例成本数据中预设；年度收益需按客户接受的实际溢价和销量另行测算。

### 4. 收率从 80% 降至 70% 的联动影响

单吨产品瓶砖需求从 $1/0.80=1.25$ t 增至 $1/0.70=1.4286$ t，增加 0.1786 t，即 14.29%。以下估算假定原料组成及副产品比例不变，因此所有随进料量变化的物流、能源、药剂、废物处理量和 HDPE 信用均按 $1.4286/1.25=8/7$ 等比例调整；这是在缺少 70% 收率工段实测清单时的敏感性近似，不代表实测结果。

**LCA：**在 100% 绿电情景下，各项清单按 $8/7$ 放大，净碳足迹为 $194.0\times8/7=221.7$ kg CO₂e/t，较 80% 收率绿电情景增加 27.7 kg CO₂e/t（14.29%）。其中原料运输上升；更多进料也带来更高电力、蒸汽、药剂和污水处理负荷。HDPE 替代信用同样按比例增加，部分抵消了新增排放。该简化假设下相对原生 PET 的减排率仍约为 90.1%。

**TEA：**基于绿电 LCOP 6,195.9 元/t，并按讲义成本明细区分进料关联项和固定项，估算如下：

| 成本变化项 | 估算变化 (元/t rPET) |
| --- | ---: |
| 瓶砖原料：5,250 → 6,000 元/t | +750.00 |
| 绿电：595 → 680 元/t | +85.00 |
| 蒸汽 | +24.29 |
| 水与烧碱 | +16.43 |
| 固废处置 | +2.90 |
| HDPE 外售抵扣增加 | −60.30 |
| **LCOP 净增加** | **+818.31** |

若维持 16,000 t/年的 rPET 产量，需处理约 22,857 t/年瓶砖，比案例的 20,000 t/年进料规模高 14.29%；在不额外计入扩产投资和固定成本的前提下，估算 $LCOP_{green,70\%}=7{,}014.2$ 元/t，较绿电基准增加 13.21%。如果不扩充进料能力、仍按 20,000 t/年处理，则产量将降至约 14,000 t/年，固定成本需由更少的产品分摊；假设各单位成本随处理规模同比例变化，LCOP 约为 $6{,}195.9\times8/7=7{,}081.0$ 元/t。后一个结果是产能固定情况下的近似值，未重算实际人员配置或设备改造费用。

### 5. 管理建议

优先通过源头分类、瓶砖验收和供应商分级降低杂质率；按批次记录进料组成、各工段质量损失和副产品回收量，持续更新 MFA。收率下降会增加每吨产品的原料及处理负担；在现有 20,000 t/年进料规模下，还会使年产量下降约 12.5%。因此应将收率、能耗、废水量和副产品回收率设为联动监控指标，再据实际工艺数据更新 LCA 与 LCOP。
