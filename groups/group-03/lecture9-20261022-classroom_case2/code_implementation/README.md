# Case 2: MFA-LCA-TEA implementation

Run `python analyze_case2.py` from this directory. The script reads the case CSV files from the sibling `case_files/data_cohort` directory, prints the calculations and data-quality checks, and recreates the PNG figures.

Requirements: Python 3 and `matplotlib` (`python -m pip install matplotlib`).

See [case2_analysis_report.md](case2_analysis_report.md) for the complete methodology, results, policy discussion, and source-data limitations.
