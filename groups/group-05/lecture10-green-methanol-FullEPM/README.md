# 第5组 · 第十讲绿色甲醇环境规划作业

主报告：[环境规划与管理方案报告](report/Environmental_Planning_Report.md)。

## 文件
- `report/`：六章报告、规划指标和工程清单。
- `code_implementation/`：物料校核、政策引擎、3000组优化、工艺图及报告生成。
- `data_cohort/`：课程输入数据。
- `figures_output/`：PNG/SVG图、工况、前沿、锚点和验证结果。
- `prompts/`：用户提供的四项任务提示词原文；任务二全文另保留在代码头部。提示词记录不替代实际完成情况，模型范围见报告附录。

## 运行
需要Python 3.10及以上。先运行 `python -m pip install -r requirements.txt`，再执行 `./run_all.ps1`。
报告采用课堂经验优化情景；独立守恒模型单独核验。结果和假设详见正文及附录。
