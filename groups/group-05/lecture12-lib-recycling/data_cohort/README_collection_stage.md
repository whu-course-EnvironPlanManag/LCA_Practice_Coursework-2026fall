采集日期：2026年11月3日。研究对象：广州市动力电池退役量、二次锂供应与区域协同回收网络。此数据包为公开资料采集与整理成果，不包含预测结果、寿命拟合或设施选址结果。

### 指标定义和限制

- `nev_stock`：新能源汽车保有量，优先使用年末值；含纯电动、插混等范围，尚未完整取得历年拆分。不能将全部新能源汽车按纯电动电池容量处理。
- `bev_stock`：纯电动车保有量，目前有2023年6月末52.6万辆这一额外观测；同日新能源车为68.14万辆。不能与年末分母混用。
- `nev_registrations`：来源原文为上牌量。是否只包括首次新车登记、是否包含迁入等仍需核实。上牌量不自动等同本地首次投放量。
- `nev_net_increase_reported`：来源公布的增量，保留原数；不用于替代上牌量或新车投放。
- `newly_added_unspecified`：来源仅称新增，未明确是新注册还是净增，单独存储。
- `cumulative_promotion`：累计推广量，不自动等于当前在用存量。2017年的约5万辆及2019年分领域推广数据保留此标记。
- `original_value`、`original_unit`保留原文精度；`value_vehicles`只做单位转换。例如26.9万辆转为269000辆，并不意味着原始资料精确到个位。
- `scope`区分全市新能源汽车、纯电动车、公交、巡游出租、货车、中小客车等。不同scope可能有交叉，不得随意相加。

## 3. 已发现的来源差异

1. **2018年保有量冲突。** 市科技局转载新闻披露134041辆，社科院蓝皮书简介称超过15万辆。两者均保留，待核实统计范围、统计时点或版本；不能取平均。
2. **2022年增量不一致。** 保有量56.3−38.2=18.1万辆，2022年报告公布增量18.2万辆。保留原文，不擅自修正。
3. **2025年增量不一致。** 保有量151.6−113.8=37.8万辆，报告公布增量37.7万辆。两者差0.1万辆，保留来源值与差异记录。
4. **2019年与2020年基准已辨明。** GZ2025图1.7中22.2对应2019年，26.9对应2020年。正文以“十四五”概述该图时起点表述宽泛；不可将22.2误标为2020年或据此修改2020年观测。
5. **2021年报告内部上牌增速可疑。** PDF第6页概述称上牌12.3万辆同比增长42%，而2020年报告上牌量5.8万辆与之不能直接核对。可能涉及口径或文字差异；未据42%反推2020年数据。
6. **政府网站公开环评不等于官方市场统计。** GZ_WASTE2025是企业建设项目环境影响报告，项目名称为“广州科雅环保科技有限公司年收集、暂存废铅蓄电池2万吨、废锂电池5000吨和废旧轮胎3000吨建设项目”。它可支持项目地址和申报规模线索，不作为全市车型结构、动力电池寿命及退役量的统计来源。

## 4. 回收网点清洗规则

原件为广州市工信局公开的《广州市新能源汽车动力蓄电池回收服务网点信息》，**清单更新时点为2022年10月20日**。网站文件上传或修改日期不是网点清单年份。

1. 按PDF表格提取全部301条，验证序号1—301连续无缺漏。
2. `*_raw`保留原始文本和换行；规范化字段只删除空白并统一全半角。没有自动改写原文疑似错字。
3. 按“规范化名称+规范化地址”精确分组。名称变体、地址前缀差异不会被擅自合并，因此235组不是独立运营网点数量。
4. `candidate_id`是该组合的SHA256前12位标识；`raw_record_ids`保存全部原清单序号，`raw_record_count`可追溯原始条数。
5. 区名仅从地址文本识别。明确的旧称萝岗区、增城市、从化市分别映射为黄埔区、增城区、从化区。未从道路名称猜测行政区。
6. 外市识别使用明确行政区名称，例如重庆市、辽宁省；不会因“中山大道”把广州地址误判为中山市。
7. `shared_address_name_count`标记同一规范化地址对应几个名称，后续应人工核验是否同址不同主体。
8. 坐标、处理能力均留空，运营状态为未核验。名单中的回收服务网点不能自动当作拆解、梯次利用或材料再生工厂。

## 5. 区人口与空间模型

来源为广州统计年鉴2025表2-2，2015—2024年，PDF第1页。人口字段：

- `registered`为户籍人口；`permanent`为常住人口。
- 全市+11区×10年×2种口径=240条。不能把全市总量和各区明细再次加总。
- 2015—2019年常住人口已按第七次全国人口普查修订，应避免拼接未修订旧年鉴。
- 区合计与全市数值的原文舍入差异保留，检查容差设置为1200人，仅用于发现提取错误，不重新平差。
- 人口数据只能支持“按人口分配车辆”的估算情景。若未取得区级车辆数据，不得将分配结果标为实测区级新能源车保有量或实测退役量。

## 6. 仍缺什么

已完成可获得来源的原件留存、结构化整理与初步质量核验；尚不足以直接启动可信的完整选址模型。详细缺口见 `data_gaps.csv`。优先补齐：

1. 早期投放队列、2023年上牌量以及登记迁移口径。
2. 分车型电池容量、BEV/PHEV结构、材料体系比例与寿命参数。
3. 最新网点状态、地理坐标和区级车辆分布。
4. 市内外再生处理设施位置、实际产能、接收条件，以及收集率、运输、成本和环境清单。

论文中的全国或全球参数若迁移到广州，应注明外推依据并建立敏感性情景。此阶段没有将论文情景参数伪装成本地观测，也没有插值、拟合、预测或地理编码。

政策时效方面，本轮检索发现工信部2026年第20号公告涉及梯次利用公告管理调整，已列入补核验清单。本地原文下载失败，不将该线索当作已经核验完成的政策参数，更不据此直接判定企业资格。
