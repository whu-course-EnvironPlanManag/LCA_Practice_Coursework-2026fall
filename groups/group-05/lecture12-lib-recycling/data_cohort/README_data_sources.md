## 计量与范围

Li与LCE通过73.88/(2×6.94)换算；kWh、kg电芯与t电池包分别计量。币种统一为人民币情景价，铜铝美元按7.04转换。功能单位为合格再生产品中1kgLi，系统扩展同时单列非锂副产物信用。元素守恒不证明假设本地化，政策数值通过不替代项目审批。
