## 1. 选题边界设定（第 1 章素材）

**推荐场景**：华中/华南某资源循环利用基地，年处理 **2 万吨退役动力电池**（LFP:NMC = 6:4，符合当前中国正极结构趋势；可设 NMC811/NMC622 混合），工艺链：**放电拆解 → 机械破碎分选 → 还原焙烧(RC) + 湿法冶金(Hy)**，对比支线：**直接正极再生(Direct Recycling)** 处理 LFP。

**关键边界决策（写进第 1 章）：**
- 空间边界：园区大门到大门（Gate-to-Gate），上游含退役电池收集运输（设平均运距 300 km），不含下游新电池制造。
- 功能单位（与 C 协商一致）：**1 t 再生正极材料当量产出**（或 1 t 电池级 Li₂CO₃ 当量），另设辅助功能单位 1 t 入厂废旧电池。
- 规划期：基准年 2026，近期 2030，远期 2035（对齐欧盟 2027/2031 法规节点与工信部 2024 规范）。
- 时间维度的 dMFA（可选加分项）：若做园区逐年进料量预测，用文献 3/5 的 Weibull 寿命分布估算区域退役量，作为园区产能爬坡的依据。

## 2. 数据工程：从 6 篇文献提取什么（第 1~2 周核心工作）

**方向 B 的主干文献是文献 4（Machala et al. 2025, Nat. Commun. 16:988）**——它是唯一给出工业级工序级能耗/水耗/碳排放/回收率的：

| 参数 | 文献 4 数值 | 用途 |
|---|---|---|
| 循环精炼全流程（RC+Me+Hy）能耗 | 44.4 MJ/kg 正极当量 | MFA 能量流 + B 的能耗合规判定 |
| 碳排放 | 6.1 kg CO₂e/kg（vs 原生 14.5） | 交给 C 做 LCA 对比 |
| 水耗 | 21.5 L/kg（vs 原生 77.3） | C 的水-碳权衡 |
| 金属回收率 | Ni/Co 95%，Li 92% | **注意：92% > 工信部 90% 红线，刚好合规——可做敏感性情景** |
| 混合金属盐 vs 单盐 | 混合 (Ni,Co)SO₄ 再降能耗 72.3% | 工艺比选变量 |

**其他文献的角色：**
- **文献 1（Peiseler 2024）**：原生锂供应碳足迹分布（卤水低排放 vs 澳矿锂辉石高排放，约 3 倍差）→ 第 5 章对比基准，A 只需把原生基准数据整理进 data_cohort。
- **文献 3（Wu 2024）**：正极材料在用存量、6–8 年退役滞后 → 若做 dMFA 进料预测时用。
- **文献 5（Zhang 2025）**：SOH 三级分流机制（>85% 直接梯次、80% 间接、<80% 再生）、湿法回收 LFP 亏损 −2.05 $/kg、直接再生 +1.30 $/kg → 决定园区进料结构与工艺配比的关键依据。
- **文献 6（Ma 2024）**：碳酸锂价格波动 5,496–84,942 $/t 对工艺经济性排序的反转 → C 的敏感性参数，A 提供对应物质流场景。
- **文献 2（Yao 2025）**：LCE 价格情景 10k/22k/50k $/t → 情景参数。

**自主拓展（≥4 项，A 负责其中数据类）**：工信部 2024 年第 42 号公告原文、GB/T 33598 系列、项目所在省水资源/电力排放因子统计、SMM 或中国汽车动力电池产业创新联盟的退役量统计。

## 3. MFA 模型设计（功能模块 1，核心代码任务）

### 3.1 工序链拓扑（园区视角，任务书明确点名这条链）

```
退役电池进厂 (20,000 t/a)
  → S1 放电+拆解        [产出：模组/电芯；损耗：电解液(含LiPF6→HF风险)、外壳钢/塑料]
  → S2 机械破碎分选      [产出：黑粉(电极粉料)、Cu箔、Al箔、隔膜；工信部要求电极粉料回收率≥98%、杂质Al<1.5%、Cu<1.5%]
  → S3a 还原焙烧(RC)     [黑粉中三元材料还原，Li转化为可浸出形态]
  → S3b 直接再生支线     [仅LFP黑粉：补锂修复，材料修复率≥99%才合规]
  → S4 湿法浸出+沉淀      [H2SO4+H2O2浸出 → 萃取/沉淀 → Li2CO3 + (Ni,Co)SO4 + FePO4/渣]
  → 产品出厂             [电池级Li2CO3、混合金属盐、FePO4、Cu、Al]
  → 环境排放             [尾渣、废水(含氟/含磷/高盐)、酸雾/有机废气]
```

### 3.2 数学形式

每个工序 j 建立元素平衡：**m_in(e) = Σ m_product(e) + m_residue(e) + m_emission(e)**，逐元素 e ∈ {Li, Ni, Co, Mn, Fe, P, Cu, Al, C, F}。

- 用 `pandas` 建工序连接矩阵（每行一个流股：来源工序、去向工序、质量、元素组成）；
- 用回收率/分配系数（来自 process_parameters.csv）逐工序解算；
- **守恒核验**：全系统 Li 输入（电池含锂）vs Li 输出（Li₂CO₃ 产品 + 尾渣 + 废水）+ 内部累积，打印平衡表，相对误差 < 0.05%（任务书硬指标）。建议同时核验 Ni/Co/C（加分）。
- 若做 dMFA 版本：园区产能按 Weibull 退役预测逐年爬坡（2026–2035），输出逐年进料/产出时序。

## 6. 易踩的坑

- **Li 守恒误差**：电池含锂系数别混用——LFP 含锂 ≈ 4.4%（按 LiFePO₄ 分子量折算），NMC811 约 7.1%；黑粉中锂含量文献间差异大，以文献 4 工业数据为准；
- **功能单位不一致**是最常见的组内返工原因，开工前和 C 白纸黑字定死；
- 第 4 章重点工程的产能/投资要和你的第 2 章通量一致（任务书明确扣分项），所以 **flows_summary.csv 里的 20,000 t/a 就是全报告的设计产能锚点**；
- 法规红线里"锂回收率 ≥90%"是**冶炼过程**口径，不是全流程口径——MFA 里要单独能算出 S3+S4 段的锂回收率供 B 判定。
