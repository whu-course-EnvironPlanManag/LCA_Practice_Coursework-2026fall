# 数据字典与来源声明（data_cohort）

本目录为“**浙江衢州华友循环资源再生产业园**（方向 B）”全部模型的**唯一参数源**。`ABC_parameters.json` 中的每个数值均在下表登记：**来源类型**分四类——`文献`（预编译文献原文/附录数值）、`法规标准`（条文阈值）、`公开口径`（园区层面的公开报道与环评受理信息）、`工程假设`（无直接公开数据，按文献机理与行业报价设定，报告正文与模型中均标注）。所有汇总结果由 `code_implementation/` 下的 4 个脚本读写，**任何数值改动只需修改 `ABC_parameters.json` 后重跑脚本即可复现**。

> 缺失数据补充原则（与 lecture10 甲醇制氢案例一致）：优先采用预编译文献原值 → 其次采用国家/行业标准与官方统计 → 再次采用同行评议文献的行业区间中位值 → 最后才设定工程假设，并给出敏感性区间与影响方向，**不编造任何“实测值”**。

| 参数（JSON 键） | 取值 | 来源类型 | 具体出处与说明 |
| :--- | :--- | :---: | :--- |
| `feedstock.share`（LFP/NMC811/NCA 份额） | 60% / 35% / 5% | 工程假设 | 反映 2023—2025 年中国退役动力电池结构（LFP 占比已超 60%）；参照文献 3（Wu et al., 2024）6 类正极材料情景与文献 5（Zhang et al., 2025）中国车型结构 |

| `active_element_fraction.NMC811`（Li/Ni/Co/Mn） | 7.60 / 51.40 / 6.45 / 6.00（%） | 文献+化学计量 | LiNi₀.₈Co₀.₁Mn₀.₁O₂ 化学计量折算（Ni 51.4%、Co 6.45%、Mn 6.0%、Li 7.6%） |
| `active_element_fraction.NCA`（Li/Ni/Co/Al） | 7.24 / 49.00 / 9.23 / 1.40（%） | 文献+化学计量 | LiNi₀.₈₀Co₀.₁₅Al₀.₀₅O₂ 化学计量（文献 4 功能单位即 NCA 当量） |

**校验**：由上述组成算得单吨来料含 Li 17.53 kg、Ni 66.10 kg、Co 8.79 kg、Mn 6.79 kg、Fe 62.45 kg、P 34.75 kg、Cu 78.40 kg、Al 105.84 kg；与文献 4 的 0.345 t NCA-eq/t 电池换算口径一致（0.345 t × 7.6% ≈ 26 kg Li 的上限口径，本报告来料含 Ni 更高、含 Li 更低，属 LFP 占 60% 的结构使然）。

- 规则来源：课程任务书第二部分、A侧法规标准汇总及`ABC_parameters.json.policy`。碳酸锂综合能耗采用严格`<2,200 kgce/t`判定；C的政策检查及Pareto筛选均按严格小于处理。
- 拐点输入：`C_lca_tea_results.json.pareto.knee`给出的绿电55%、LFP适用来料直再60%；总来料LFP/NMC811/NCA为60%/35%/5%。NMC/NCA中30%进入RC_Hy。
- Direct产粉97%是过程产率，不等同于法规定义的材料修复回收比重；黑粉Cu/Al杂质、研发费用比例、梯次产能等无实测或设计凭证，`b_policy_review`保留为待核验。
- 欧盟2031/2036再生锂含量分别为6%/12%。C政策测试W1/W2/W3分别输入3%/6%/8%；C TEA的`recycled_content_li`为6%。这些是情景值，不能相互代替。当前均低于2036目标。
- C给定碳价80元/t CO₂e及欧盟溢价1,200元/t LCE只用于条件性估值。CCER需另行证明方法学适用、项目登记、核证签发；欧盟溢价需产品、出口合同和认证依据。
- C TEA已含450元/t环境管理成本及水费；当前没有可用于法定环保税、水资源税计算的地方税额、应税排放量、取水量与适用档次，不另行推算或重复计费。
