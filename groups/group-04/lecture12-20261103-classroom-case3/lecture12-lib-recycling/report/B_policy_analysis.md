# B部分：政策合规、规制情景与方案接口核查

**规划对象**：浙江衢州华友循环资源再生产业园  
**核算边界**：1 t 混合退役电池（LFP 60%、NMC811 35%、NCA 5%）；一期设计规模 20,000 t/a  
**数据口径**：下表为模型情景值，不代表企业实测或法定认证。完整规则、证据状态与政策财务估算见[政策与规制核查补充报告](B_政策与规制核查补充报告.md)。

## 2. C推荐拐点的扩展核查

C的帕累托拐点为绿电消纳55%、适用LFP来料直接再生比例60%。拐点模型结果如下：

| 指标 | C模型值 | 核查阈值 | 指标判定 |
|---|---:|---:|---|
| 冶炼锂回收率 | 92.46% | ≥90% | 通过 |
| NiCoMn综合回收率 | 98.00% | ≥98% | 通过（合并口径） |
| 电极粉料回收率 | 98.00% | ≥98% | 通过 |
| Cu/Al回收率 | 98.00% | ≥98% | 通过（合并口径） |
| 氟固化率 | 99.50% | ≥99.5% | 达到模型阈值；仍须监测核证 |
| 碳酸锂综合能耗 | 约7,200.68 kgce/t LCE（按C附件电力、热能折标值及LCE产量重算） | <2,200 kgce/t | 不通过；须统一能耗边界、联产品分摊口径并以计量数据复核 |
| 工艺废水循环利用率 | 92% | ≥90% | 达到模型阈值；仍须监测核证 |
| 再生利用设计能力 | 20,000 t/a | ≥5,000 t/a | 通过（设计规模） |

**中国全口径结论：当前模型核查不通过，完整准入仍待核验。** 除能耗复算超过阈值外，还缺同口径的直接再生材料修复回收比重、黑粉铜/铝杂质化验、研发费用占综合利用业务收入比例，以及梯次利用能力和适用性凭证。Direct产品产率97%不能直接替代法规定义的材料修复回收比重。C对Ni/Co/Mn、Cu/Al采用合并指标，逐元素达标仍需检测或物料平衡记录。旧版政策结果中的919.38 kgce/t采用了不同分摊口径，不能与C附件能耗核算混用；须先用统一边界和企业能源计量数据复核。

## 3. C模块结果对规划方案的约束

C模块给出的产线配置、产品形态及药剂矩阵用于确定工程规模与运行控制重点，不作为法规实测凭证。

| C模块决策项 | 结果 | B模块规划转译 |
|---|---|---|
| 一期产能配置（20,000 t/a） | Direct 7,200、Hy 10,400、RC_Hy 2,400 t/a；占混合来料36%／52%／12% | P-02/P-03按路线分区配置；来料吨数为电池质量当量，不等同黑粉量 |
| 规模扫描 | 20,000至100,000 t/a单位投资由36,000降至22,213元/(t/a)；LCOR由−5,726改善至−7,081元/t | 采取分期扩建；二期60,000 t/a仍以来料保障和环境许可为前提 |
| 产品形态 | 混合盐GWP 1,140.7 kg CO₂e/t、水耗8.80 m³/t、LCOR−5,726元/t；离散盐分别为1,434.9、10.91、−4,904 | P-02优先混合盐短流程，离散盐精制按订单与认证需求设置 |
| 湿法四药剂 | 692元/t、162.2 kg CO₂e/t；Na₂CO₃与H₂SO₄合计占药剂隐含碳64.7% | 优先核查沉锂剂减量/替代和酸回用；须用运行台账验证药剂单耗 |
| 绿电拐点 | 绿电55%、LFP适用来料直再60%；GWP 1,140.7 kg CO₂e/t、水耗8.80 m³/t、LCOR−5,726元/t | 一期以55%为情景目标并按年度绿电凭证核算；2035年100%绿电是远期情景，不是现状或已落实供应 |

C附件同时存在能耗口径冲突：其LCA/TEA模型按电力折标系数0.1229 kgce/kWh、热能折标系数34.12 kgce/GJ计算，拐点约为7,200.68 kgce/t LCE；既有政策结果表中的919.38 kgce/t采用联产品分摊。该差异会改变能耗合规判定，须在定稿前按适用法规口径及企业计量数据统一，不能以旧值宣称达标。产能扫描的60,000 t/a配置（绿电55%）与C报告2035年100%绿电目标态也属于不同情景，不应混作同一组结果。

## 6. 结论与后续核验

1. W1未达到多项回收率、氟固化及水循环约束；W2、W3的11/11为原C政策引擎结果，其能耗算法与C LCA/TEA口径未统一，不能据此认定能耗合规。
2. 推荐拐点的回收率、水循环及设计产能等已建模指标达到阈值；按C附件能耗公式复算则超过2,200 kgce/t。正式结论须待统一分摊方法并以能源计量数据复核，同时补齐逐元素检测、材料修复口径、杂质、研发费用及梯次能力证据。
3. 当前6%再生锂含量达到2031模型目标，不满足2036年12%目标；欧盟产品级含量、数字护照和碳足迹证明仍须按法规适用范围核查。
4. 路线分配Direct:Hy:RC_Hy为36:52:12，对应7,200/10,400/2,400 t/a。
5. 碳价值与再生锂溢价只作为政策情景，不计入当前基准财务结果；环保税、水资源税暂不估算，待取得地方适用税额及排放/取水实测数据后再核算。C模块的混合盐、药剂和绿电结果用于工程选择，不能替代运行监测与合规凭证。
