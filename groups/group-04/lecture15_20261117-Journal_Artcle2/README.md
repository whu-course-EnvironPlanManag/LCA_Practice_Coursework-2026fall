# 第十五讲：全球磷循环物质流分析

## 运行

在本目录运行：

```powershell
python run_analysis.py
```

依赖见 `requirements.txt`。程序使用相对路径读取 `data/raw/`，并将表格、CSV、交互式桑基图和简要结果写入 `results/`。

## 任务对应

- 任务 1：`ACSPModel` 读取 2022 年作物纯磷产出，估算作物吸收、残体、田间损失和土壤存量变化。
- 任务 2：将矿业、化肥、种植、养殖、居民消费、粪肥及污水回收连接成守恒账本；输出逐子系统和全系统检查，并生成 `results/sankey_2022_estimate.html`。
- 任务 3：用联合国人口中位情景外推 2050 BAU；比较减施 20%、粪肥利用率 75%、鸟粪石回收率 60% 的 3R 情景；在 343 个参数组合上拟合含均值中心化交互项的标准化回归。

## 数据口径与限制

1. `Agricultural products_P_result...xlsx` 的 `World` 行是论文预计算的纯磷结果。程序使用该行，避免将国家、洲和世界汇总重复相加，也避免对已是纯磷的数据再次乘含磷系数。含磷系数表仍作为原始输入保留，用于类别说明和数据溯源。
2. 化肥施用量按 FAOSTAT 国家级 `Agricultural Use`、单位吨筛选，排除区域汇总，再按 P2O5 中磷的质量分数 0.4364 换算。当前文件最新年份为 2021；2022 与 2050 分别使用联合国人口估算和中位预测，假设人均化肥使用量不变。
3. 磷矿表末尾的 2022 列无列名且只有美国一条记录，不能当作完整全球年度值。脚本使用最新完整年份并按人口比例估算 2022 供应结构。
4. 源数据没有提供完整的全球五子系统年度流量矩阵、作物食用/饲料分配、基准粪肥/污水回收率或实测田间损失系数。因此 `model_assumptions.csv` 明列这些假设；桑基图和情景结果用于实训核算与情景比较，不应表述为对论文全部图表的精确复现。
5. 回归自变量来自确定性的情景网格。系数、显著性和 `R-squared` 描述本模型响应面，不是实测样本上的因果检验。`cross_sensitivity_samples.csv` 保留所有 343 个输入组合，便于复核。

## 结果目录

- `lecture15_results.xlsx`：汇总历史序列、2022 分类/流量、守恒检查、2050 情景、回归和假设。
- `global_harvest_p_1961_2022.csv`、`global_crop_categories_*.csv`：源表提取及分类序列。
- `flows_2022_estimate.csv`、`mass_balance_checks.csv`：桑基图输入账本和守恒检查。
- `scenarios_2050.csv`、`cross_sensitivity_*.csv`：情景结果、回归样本和统计结果。
- `sankey_2022_estimate.html`：交互式桑基图。
- `全球作物磷历史趋势.png`：1961—2022 年全球作物收获磷折线图。
- `2022作物磷分类.png`：2022 年产品类别磷流量条形图。
- `2050情景对比.png`：2022 估算、2050 BAU 与 3R 情景对比图。
- `3R敏感性回归系数.png`：主效应与交互项的标准化回归系数图。
- `analysis_report.md`：运行后自动生成的数值摘要与口径说明。
- `规划建议与复现报告.md`：中文复现分析与量化规划建议。
