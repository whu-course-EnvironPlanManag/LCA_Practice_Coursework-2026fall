## 一、核算口径与关键假设

| 项目 | 取值 | 来源 |
| :--- | :--- | :--- |
| 基准收率 Y₀ | 80.0% → 1 t rPET 耗 1.25 t 瓶砖 | `mfa_mass_balance.csv` |
| 年处理瓶砖 | 20,000 t/a | 讲义第四节 |
| 年产量 | 20,000 × Y | 由收率决定 |
| 公用工程与药剂 | 电 850 kWh、汽 2.0 GJ、碱 15 kg、水 2.5 m³、污水 2.2 m³（均为 t rPET） | `lci_emission_factors.csv` |
| 需焚烧固废 | 65 kg / 1000 kg 瓶砖 | MFA：标签 20 + 细料 5 + 杂色片 40 |
| 副产 HDPE | 75 kg / 1000 kg 瓶砖 | MFA |
| 固定成本 | 人工 350 万 + 维保 84 万 + 折旧 266 万 = 700 万元/年 | `tea_cost_parameters.csv` |

**规模折算**：收率降到 Y 时，处理同样 1 t 产品需要 1/Y 吨瓶砖，电、汽、碱、水、污水、固废、副产物均按进料量成比例放大，折算系数 `scale = 0.80 / Y`。固定成本按当年产量 `20,000 × Y` 摊薄。

## 二、MFA 质量平衡校验

| 项 | 质量 (kg) | 占比 |
| :--- | ---: | ---: |
| 输入：废瓶砖 | 1,000.0 | 100.0% |
| 输出：主产品 rPET | 800.0 | 80.0% |
| 输出：副产 HDPE | 75.0 | 7.5% |
| 输出：废标签膜 | 20.0 | 2.0% |
| 输出：泥沙干灰 | 25.0 | 2.5% |
| 输出：洗涤 COD 杂质 | 35.0 | 3.5% |
| 输出：HDPE 夹带损失 | 5.0 | 0.5% |
| 输出：杂色片与细粉 | 40.0 | 4.0% |
| **输出合计** | **1,000.0** | **100.0%** |

闭合误差 0.00 kg，程序内置断言：不守恒即终止核算。

主产品收率 Y = 800/1000 = **80.0%**，吨产品物耗 = 1/0.8 = **1.25 t 瓶砖**。

## 三、LCA 净碳足迹：基准 vs 绿电

### 3.1 基准情景（华中电网 0.55 kg CO₂e/kWh）

| 清单项 | 活动水平 | 排放因子 | 碳足迹 (kg CO₂e/t) |
| :--- | :--- | :--- | ---: |
| 原料运输 | 1,250 kg | 0.12 kg CO₂e/kg | 150.00 |
| 电力 | 850 kWh | 0.55 kg CO₂e/kWh | 467.50 |
| 蒸汽 | 2.0 GJ | 65.0 kg CO₂e/GJ | 130.00 |
| 烧碱 | 15 kg | 2.10 kg CO₂e/kg | 31.50 |
| 新鲜水 | 2.5 m³ | 0.38 kg CO₂e/m³ | 0.95 |
| 污水处理 | 2.2 m³ | 2.75 kg CO₂e/m³ | 6.05 |
| HDPE 避免负荷 | −93.75 kg | 1.60 kg CO₂e/kg | −150.00 |
| **净碳足迹** | | | **636.00** |

与讲义基准 636.0 完全一致。

### 3.2 绿电情景

仅两项参数变化：电网因子 0.55 → **0.03** kg CO₂e/kWh；电价 0.65 → **0.70** 元/kWh（绿电溢价 0.05）。清单只改电力一行：

- 电力碳足迹：850 × 0.03 = **25.50** kg CO₂e/t（原 467.50，下降 442.00）
- 其余各项不变，净碳足迹 = 636.00 − 442.00 = **194.00 kg CO₂e/t**

| 指标 | 基准 | 绿电 |
| :--- | ---: | ---: |
| 净碳足迹 (kg CO₂e/t) | 636.0 | **194.0** |
| 相对原生 PET（2,250）减碳率 | 71.7% | **91.4%** |
| 吨产品净减排量 (kg CO₂e) | 1,614.0 | **2,056.0** |

绿电使碳足迹再降 **69.5%**，减碳率由 71.7% 提升到 91.4%。

## 四、TEA 平准化成本：基准 vs 绿电

### 4.1 基准情景（按 CSV 分项口径）

| 成本项 | 计算 | 元/t rPET |
| :--- | :--- | ---: |
| 原料废瓶砖 | 1.25 t × 4,200 | 5,250.00 |
| 电力 | 850 kWh × 0.65 | 552.50 |
| 蒸汽 | 2.0 GJ × 85 | 170.00 |
| 烧碱 | 0.015 t × 3,200 | 48.00 |
| 新鲜水 | 2.5 m³ × 4.5 | 11.25 |
| 固废处置 | 0.08125 t × 250 | 20.31 |
| HDPE 副产抵扣 | −0.09375 t × 4,500 | −421.88 |
| **变动成本小计** | | **5,630.19** |
| 固定成本摊薄 | 700 万 ÷ 16,000 t | 437.50 |
| **LCOP** | | **6,067.69** |

年毛利 = (7,600 − 6,067.69) × 16,000 = **2,451.7 万元/年**。

### 4.2 绿电情景

电价 +0.05 元/kWh，仅电力一项变化：

- 电力成本 552.50 → 595.00，增加 **42.50 元/t**
- LCOP = 6,067.69 + 42.50 = **6,110.19 元/t**
- 增幅 = 42.50 / 6,067.69 = **+0.70%**

| 指标 | 基准 | 绿电 | 变化 |
| :--- | ---: | ---: | ---: |
| LCOP (元/t) | 6,067.69 | 6,110.19 | +42.50 |
| 吨毛利 (元) | 1,532.31 | 1,489.81 | −42.50 |
| 年毛利 (万元) | 2,451.7 | 2,383.7 | −68.0 |
| 年毛利率 | 20.2% | 19.6% | −0.56 pt |

> 若以讲义基准 LCOP 6,153.4 为起点，则绿电 LCOP = **6,195.9 元/t**，增量与增幅不变（+42.50，+0.69%）。

**关键结论**：用 **0.7% 的成本上升换 69.5% 的碳减排**，杠杆极高。

## 五、源头敏感度：收率 80% → 70%

### 5.1 传导链

收率下降 → 吨产品耗瓶砖 1.25 → **1.4286 t**（+14.3%）→ 所有随进料量变化的环节同比例放大 → 当年产量由 16,000 降至 **14,000 t**，固定成本摊薄上升。

### 5.2 定量结果

| 指标 | Y=80% | Y=70% | 变化 |
| :--- | ---: | ---: | ---: |
| 吨耗瓶砖 (t) | 1.2500 | 1.4286 | +14.3% |
| 原料运输 (kg CO₂e) | 150.00 | 171.43 | +14.3% |
| 电力碳足迹 (kg CO₂e) | 467.50 | 534.29 | +14.3% |
| 蒸汽碳足迹 (kg CO₂e) | 130.00 | 148.57 | +14.3% |
| HDPE 信用 (kg CO₂e) | −150.00 | −171.43 | — |
| **净碳足迹 (kg CO₂e/t)** | **636.0** | **726.9** | **+90.9 (+14.3%)** |
| 减碳率 vs 原生 PET | 71.7% | 67.7% | −4.0 pt |
| 变动成本 (元/t) | 5,630.19 | 6,434.50 | +804.31 |
| 固定成本摊薄 (元/t) | 437.50 | 500.00 | +62.50 |
| **LCOP (元/t)** | **6,067.69** | **6,934.50** | **+866.81 (+14.3%)** |
| 年产量 (t) | 16,000 | 14,000 | −12.5% |
| 年毛利 (万元) | 2,451.7 | 931.7 | **−62.0%** |

注：副产 HDPE 随进料放大，其避免负荷信用同步增加，部分抵消了上游负荷的增长，所以净碳足迹增幅与成本增幅虽同为 14.3%，但绝对值构成不同。

### 5.3 绿电 + 低收率叠加

| 情景 | 净碳足迹 (kg CO₂e/t) | LCOP (元/t) |
| :--- | ---: | ---: |
| 基准 | 636.0 | 6,067.69 |
| 绿电 | 194.0 | 6,110.19 |
| 低收率 | 726.9 | 6,934.50 |
| 绿电 + 低收率 | **221.7** | **6,983.07** |

绿电能把 70% 收率下的碳足迹压到 221.7，仍优于基准情景的 636.0；但成本无法被绿电对冲，LCOP 升至 6,983.07。

## 六、与讲义基准值的口径核对

讲义 LCOP 为 **6,153.4 元/t**，本模型按 CSV 分项计算为 **6,067.69 元/t**，差额 85.71 元/t，可完整分解：

| 差异来源 | 讲义口径 | CSV 分项口径 | 差额 |
| :--- | ---: | ---: | ---: |
| 新鲜水 + 烧碱 | 115.00（聚合定额） | 59.25（48.00 + 11.25） | +55.75 |
| 管理、保险及摊销 | 196.40（含折旧 166.25） | 未单列 | +30.15 |
| 合计 | | | **+85.71**（分项合计 85.90，尾差 0.19 来自讲义汇总取整） |

差额属讲义汇总表的取整与聚合口径，不影响情景间的比较与增量结论（绿电增量 42.50 元/t 完全不受影响）。

> 回收期说明：本模型按"建设期不计入、投产后第 1 年起算"计算，基准静态回收期 1.33 年、动态 1.47 年（WACC 8%）；讲义 2.6 年为含建设期的另一口径，两者不可直接比较。

## 七、绿色溢价定价与营销策略建议

**1. 成本传导底线**：绿电使 LCOP 上升 42.50 元/t（+0.70%）。建议对绿电批次单独定价 **+50～80 元/t**（约 0.66%～1.05%），既覆盖溢价又保留议价空间。

**2. 碳资产对冲**：绿电相对基准每吨减排 442 kg CO₂e，16,000 t 年产量对应 **7,072 t CO₂e/年**。按 100 元/t CO₂e 的内部碳价折算约 70.7 万元/年，可完全覆盖 68.0 万元/年的绿电增量成本——**绿电溢价在碳价 ≥ 96 元/t 时即为零成本**。

**3. 客户价值主张**：面向国际饮料品牌，主打"91.4% 减碳 + 100% 绿电 + 可追溯 PCF"。用产品碳足迹标签（636 → 194 kg CO₂e/t）量化 Scope 3 减排，直接对接客户范围三目标。

**4. 风险提示（敏感度结论）**：收率每下降 10 个百分点，LCOP 增加 **866.81 元/t**、碳足迹增加 90.9 kg CO₂e/t。这一冲击是绿电溢价（42.50 元/t）的 **20 倍**。因此**前端分选与瓶砖品质管控的优先级远高于绿电采购**：绿电决定"故事讲得好不好"，收率决定"企业活不活得下去"。
