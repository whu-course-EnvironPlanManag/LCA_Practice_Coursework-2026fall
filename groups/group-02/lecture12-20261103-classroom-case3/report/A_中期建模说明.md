  输入 Li 为 0 时判 `undefined_not_pass`（零输入不构成守恒证明）；任一端缺失则返回 `not_available`，不以 0 代入。

## 4. 市域动态物质流分析（dMFA）：结果

老师最新要求以**动态物质流分析**为核心方法，本节即主交付的第 1、3 章素材。计算脚本 `dmfa_yichang.py`，
图表 `plot_dmfa.py`，数据源 `A_dMFA数据交接包_20261103`。

### 4.1 方法与边界

| 要素 | 设定 | 出处 |
| :--- | :--- | :--- |
| 建模对象 | 2010—2025 年新车**首次装配**的整包电池队列（分 LFP / 未细分三元） | `DMFA-01`（`YC_DMFA01_RECON_V2`，条件重建） |
| 时间约定 | 年末入队，年龄 0 进入；首次退役从年龄 1 起；2009-12-31 队列初值 0 | A01、A17 |
| 存活函数 | L(age)=exp(−(age/scale)^k)；退役分布 f(age)=L(age−1)−L(age)，**尾部不重归一化** | `lifetime_tail.renormalize_truncated_pmf=false` |
| 寿命参数 | LFP：k=3.1，scale=5.5 a（均值 4.92 a）；未细分三元：k=2.1，scale=7.3 a（均值 6.47 a） | `DMFA-S001`（WU 2024，Table S1，Developing） |
| 正规收集率 | 三情景 c=0.65 / 0.85 / 1.00 | `DMFA-S002`（pp.8、23） |
| 整包 Li 强度 | BEV/PHEV 10.266、公交 10.875、中卡 13.659 kg Li/t 整包（LFP） | `DMFA-S002`、`DMFA-S011`（0.087 kg Li/kWh × 118/125/157 Wh/kg） |
| 计算式 | R(t)=Σ_τ I(t−τ)·f(τ)；C(t)=c·R(t)；S(t)=Σ_u I(u)·L(t−u) | 见 4.4 恒等式 |

### 4.2 结果（首装队列，2010—2040）

| 指标 | C065（c=0.65） | C085（c=0.85） | C100（c=1.00） |
| :--- | ---: | ---: | ---: |

| 累计首次退役 2010—2040（t） | 29,765 | 29,765 | 29,765 |

结构特征：2010—2017 年退役量极小（前期装机少、寿命短），2023—2025 年集中装机使退役量在 2029 年达峰；
2040 年后队列基本释放完毕（残留 25.7 t）。**收集率只改变 C(t)，不改变 R(t)**，因此三情景的退役列完全相同。

### 4.3 必须随结果一起写的口径说明

1. 2026—2040 段是**既有首装队列的剩余释放**，不是全市未来退役预测；未来新增装机未建模（`D01-FUT` 阻断），
   因此**不能**由本表得出"2040 年全市退役量为 0"。
2. 2025 年末 27,493 t 是**建模队列存量**，不是宜昌在用车电池存量（`D05-FLEET` 未解）。
3. `collected ≠ recycled ≠ park feed`：正规收集量还要经梯次分流（M01）才得到再生处理量，再经市域→园区链接
   （`D-PARK-LINK`）才谈得上 8 万 t/a 园区来料。**本表不提供园区进料量**。
4. Li 仅覆盖 LFP 部分（`partial_LFP_only`）；未细分三元 Li 整列为 null，**不取 NMC622/811 平均**。故上表 Li 是下界口径。
5. 寿命参数为发展中地区的文献代理（LFP 均值 4.92 a 偏短）；若 scale 增大，退役峰值将后移且峰值降低，
   至少要给出"peak 年份—峰值"的敏感性对照，不得只报单一情景。

## 5. 园区功能分区与重点工程骨架

- 功能分区 8 个：Z1 来料接收与暂存、Z2 放电与拆解、Z3 破碎分选、Z4 湿法/直接再生主工艺、
  Z5 产品与副产品、Z6 废水与尾气治理、Z7 固废与危废暂存、Z8 公用工程与检测办公（上风向）。
- 重点工程 6 项（工程-01 接收与智能仓储、工程-02 放电与智能拆解、工程-03 破碎分选与黑粉制备、
  工程-04 湿法浸出与产品精炼、工程-05 黑粉直接再生（可选并行）、工程-06 三废治理）。
- 布局逻辑：物流自西向东串联（Z1→Z2→Z3→Z4），产物经 Z5 外运，废液送 Z6、固废送 Z7；
  办公与公用工程置于上风向，安全缓冲区以红色虚线示意。
- **规模与投资一律为空**：设计规模依赖 M01/M02/M09，投资依赖 M12（属成员 C），详见
  `capacity_interfaces.csv` 的 IF-01–IF-06 公式。
