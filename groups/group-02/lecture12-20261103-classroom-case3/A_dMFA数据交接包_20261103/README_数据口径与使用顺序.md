# 宜昌市 dMFA 最终交接数据集

这是成员A本轮交付快照。它整合旧资料包、DMFA-01重建V2、DMFA-02—07、全部假设、引用及未解决输入。

## 入口

IDE读取 `yichang_dmfa_dataset.json`。这是唯一数据入口，无需再合并旧JSON或CSV。旧资料完整内嵌于 `legacy_park_handoff.payload`，用于查证；其中80000 t/a、60%/40%及旧IDE指令不是市域默认输入。

## 三个可用范围

1. 历史首装流入：2010—2025年度重建新增车辆、4类原型、总包质量和能量流入。全为条件估计，不是宜昌注册年报。
2. 条件首用队列：选择 `EXP_V2_HLFP_WU_C065`、`C085`或`C100`，计算首用在用存量、首次退出及正规收集。LFP高占比是设计情景，Wu寿命是借用值，收集率是文献情景。
3. 既有队列释放：2026—2040只观察2010—2025队列的剩余退出。未来新增被排除是队列定义，不能称宜昌未来不新增电池。

真实全市2026—2040总预测、替换电池队列、完整总Li和园区进料仍未就绪。未来装机、替换、真实迁移、混合三元含Li等保持null。

## 关键口径

- 本市原始观测见 observations；重建结果见 dmfa_inputs.DMFA-01.annual_records；原型见 vehicle_class_prototypes。
- 2022/2023年度数作年末锚点、8000辆作净增近似、零净迁移、早期忽略及固定车型结构都是假设。见 assumptions。
- 车辆寿命 k=2.07、scale=14.46年只用于重建车辆数；电池寿命用另一套Wu参数。二者不能互换。
- 新车首装不含在用车替换电池。车辆存量不是电池首装队列存量。99750是插值车辆数，不是t整包。
- 计算首用电池库存时，使用与退出量一致的历史电池队列及电池存活函数，不将整车存活直接用作电池存活。
- 年末入队，新电池进入时年龄0，第一次年退出从年龄1开始。寿命截断尾部不重新归一化。
- 退役/退出先算，正规收集随后乘情景c；c缺失不应阻止计算退出量本身。
- H_LFP_HIGH只有LFP及未细分三元。NMC622/811份额未定，其他体系省略，不是全市完整化学结构。
- Li按每个车型配套的kWh含Li强度和包比能量换算。公交和货车不能直接套紧凑型BEV的10.266 kg Li/t。
- 未细分三元Li为null，不取622/811平均。可算LFP部分Li，但必须标为partial_LFP_only。
- kg Li/t整包除以1000才是kg Li/kg整包。不要再次乘电芯/整包比，也不要用粉料品位替代。
- 正规收集不是全部进入再生，更不是全部进入宜昌邦普或假想园区。M01及园区市外来料等仍待补。

## 来源和版本

所有新引用和旧45项来源集中在 sources，参数用 source_ids 连接。新增引用在此前检索中核对；本次是数据整合，没有再次下载这些网页附件。

早期全国销量存在版本/统计口径差异，已保留冲突。参考情景选定一个版本用于形状，不取平均。2026年资料用于2025年末后验插值，不是2025当时的前瞻预测。

`校验报告.json`检查数据结构、来源/假设引用、与旧包的完整一致性、数量与质量分配及锚点回代。锚点一致是构造约束，不是独立验证；本次没有执行退役模型或得到退役预测结果。

- yichang_dmfa_dataset.json：自包含输入。
- yichang_dmfa_dataset.schema.json：主要接口的JSON Schema。
- IDE_数据接入提示词.md：接入及输出口径。
- 校验报告.json：保存后校验记录。
- 文件索引.json：文件哈希与入口。

主数据、来源、假设、观测和派生情景应分别读取；不要将它们当成多批流量重复累加。使用完整精度数值计算，展示时再四舍五入。
