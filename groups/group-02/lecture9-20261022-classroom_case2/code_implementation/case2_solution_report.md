## 一、任务 1：MFA 反应-循环回路求解与元素守恒

### 1. 各单元质量守恒校验（kg/t 产品）

| 守恒方程                      | 左端 LHS |                     右端 RHS |  结果 |
| :------------------------ | -----: | -------------------------: | :-: |
| 混合器 S07 = S01 + S02 + S06 | 6261.0 | 1423 + 198 + 4640 = 6261.0 |  OK |
| 反应器 S08 = S07             | 6261.0 |                     6261.0 |  OK |
| 分离器 S08 = S09 + S10       | 6261.0 |       1575 + 4686 = 6261.0 |  OK |
| 分流器 S10 = S06 + S11       | 4686.0 |         4640 + 46 = 4686.0 |  OK |

CSV 内各单元质量严格闭合，无泄漏。

### 2. 单程转化率与总体转化率的解耦（`scipy.optimize.fsolve`）

循环反应器的经典关系（以 CO₂ 为关键组分）：

$X_{\text{overall}} = \frac{X_{\text{single-pass}}}{1 - f_{\text{cycle}}\,(1 - X_{\text{single-pass}})}$

其中 $f_{\text{cycle}}$ 为未反应气返回反应器的循环比例。取单程转化率 $X_{sp}=25\%$：

- **反解**：目标总体碳利用率 96%，解得所需循环比例 $f_{\text{cycle}} = 0.9861$（约 98.6%）。
- **正算**：给定分流器循环比例 99%，反推总体转化率 $X_{\text{overall}} = 0.9709$（97.1%）。

> 结论：98% 以上的超高循环比例是"单程仅 25%、总体却达 96%"的唯一来源。

### 3. 循环比与总碳利用率（由 CSV 流股直接推导）

| 口径               | 计算式                        |                数值 |
| :--------------- | :------------------------- | ----------------: |
| 新鲜气量（CO₂ + H₂）   | 1423 + 198                 |           1621 kg |
| 循环比（循环气 / 新鲜气）   | 4640 / 1621                |         **2.862** |
| 循环比（反应器入口 / 新鲜气） | 6261 / 1621                | **3.862 ≈ 3.8:1** |
| 总碳利用率 η\_carbon  | 产品碳 374.9 / 新鲜 CO₂ 碳 388.4 |        **96.53%** |

> 讲义中的"循环比 3.8:1"采用**反应器入口/新鲜气**口径（6261/1621=3.86）；"总碳利用率 96.0%"为约整口径，实际流股核算为 96.53%。

### 4. C / H / O 三元素守恒核算（合成反应回路）

$主反应:\ \text{CO}_2 + 3\text{H}_2 \rightleftharpoons \text{CH}_3\text{OH} + \text{H}_2\text{O}$

| 元素        |  输入 (kg) |                                输出 (kg) |           差值 |
| :-------- | -------: | -------------------------------------: | -----------: |
| 碳 C       |  388.358 |                甲醇 374.875 + 驰放气 13.483 |      0.0000% |
| 氢 H       |  198.000 |      甲醇 125.843 + 水 64.343 + 驰放气 7.814 |      0.0000% |
| 氧 O       | 1034.609 |    甲醇 499.345 + 水 510.625 + 驰放气 24.639 |      0.0000% |
| **驰放气反推** |        — | 13.483 + 7.814 + 24.639 ≈ **45.94 kg** | CSV 标注 46 kg |

驰放气作为"入-出"差额反推，质量 45.94 kg 与标注 46 kg 吻合。

## 二、任务 2：LCA 绿电悖论 + TEA 电价敏感性

### 1. 净碳足迹（GWP100，基准煤制甲醇 2600 kg CO₂e/t）

| 情景           |      排放因子 EF |                  净碳足迹 |           较基准 |
| :----------- | -----------: | --------------------: | ------------: |
| 情景 A：100% 绿电 | 0.035 kg/kWh | **−1044.1 kg CO₂e/t** | 净负碳，减排 140.2% |
| 情景 B：区域工业电网  | 0.550 kg/kWh | **+4531.3 kg CO₂e/t** |    反向增排 74.3% |

**绿电悖论成因**：火电发电 ≈40% × 电解 ≈64% × 合成损耗 三重热力学折损，使每焦耳甲醇化学能背后消耗数倍化石煤炭。ΔGHG（绿电）= 2600 − (−1044.1) = **3.644 t CO₂e/t**。

### 2. LCOM 平准化成本线性模型

$LCOM = 10826\cdot p + 1238.37 \quad (p=\text{电价},\ \text{元/kWh})$

电耗强度 10826 kWh/t，非电成本（CAPEX 摊销 + 原料 + 运维 − 副产 O₂ 外售）固定 1238.37 元/t。

### 3. 边际减排成本（MAC）与临界电价

$MAC = \frac{LCOM - 2500}{\Delta GHG} = \frac{LCOM - 2500}{3.644}$

|   电价 |   LCOM |    绿色溢价 |        MAC |
| ---: | -----: | ------: | ---------: |
| 0.15 | 2862.3 |  +362.3 |   **99.4** |
| 0.35 | 5027.5 | +2527.5 |  **693.6** |
| 0.55 | 7192.7 | +4692.7 | **1287.7** |

**商业自平衡临界电价**：令 MAC = 全国碳价 100 元/t，解得

$p^* = \frac{100\times 3.644 - 1238.37 + 2500}{10826} \approx 0.15\ \text{元/kWh}$

仅当电价降至约 0.15 元/度的大基地消纳场景，绿色甲醇才能依托国内碳市场抹平绿色溢价。

### 4. 规划决策矩阵

| 情景      |   电价 | LCOM |        净碳 |   MAC | 规划结论         |
| :------ | ---: | ---: | --------: | ----: | :----------- |
| 大基地清洁消纳 | 0.15 | 2862 |     −1044 |  99.4 | 典范可行，碳交易可自平衡 |
| 沿海工商业绿电 | 0.35 | 5027 |     −1044 | 693.6 | 严重倒挂，需出口航运溢价 |
| 常规工业电网  | 0.55 | 7193 | **+4531** |  倒挂恶化 | 规划禁区，严禁立项    |

## 三、任务 3：工艺流程图（BFD）

脚本 `plot_case2_process.py` 基于 `schemdraw` 绘制带循环回路的方框工艺流程图：

- 单元链：气体混合器 → 固定床反应器（250℃·5.0 MPa）→ 冷凝高压气液分离器 → 精馏提纯 → 精甲醇产品，副产生成水回流电解槽。
- 循环回路：分离器顶部气相 4686 kg 经分流器 99% 回流（4640 kg）至混合器，1% 驰放（46 kg）送锅炉。

## 四、工程与环境规划启示

**绿色化工的经济性与环境效益完全由上游电力的碳强度与价格共同锚定**——循环回路只是把"单程 25%"拉升到"总体 96%"的工程手段，而决定项目生死的是电价：0.15 元绿电即自平衡、0.35 元需政策输血、0.55 元电网则沦为"既贵又脏"的双输禁区，因此沙戈荒大基地区才是绿氢甲醇唯一合理的空间落点。
