| 指标 | 数值 | 说明 |

## 二、任务 1.1 —— LCA 净碳足迹“绿电再核算”

### 1. 边界参数变更

| 参数 | 基准 | 绿电情景 | 变化 |
| :--- | :---: | :---: | :--- |
| 电网碳排放因子 | 0.55 kg CO₂e/kWh | **0.03 kg CO₂e/kWh** | −0.52 |
| 电力消耗量（吨产品） | 850 kWh | 850 kWh（不变） | — |

### 2. 生命周期清单（LCI）调整与计算过程

绿电情景下，**仅电力分项**的碳排放因子发生变更，其余分项活动水平与基准一致：

$$
\text{电力碳足迹}_{\text{green}} = 850\ \text{kWh} \times 0.03\ \text{kg CO}_2\text{e/kWh} = 25.5\ \text{kg CO}_2\text{e/t}
$$

（基准电力分项：$850 \times 0.55 = 467.5\ \text{kg CO}_2\text{e/t}$，单此项即减排 **442.0 kg CO₂e/t**。）

| 过程分项 | 基准碳足迹 (kg CO₂e/t) | 绿电情景 (kg CO₂e/t) |
| :--- | :---: | :---: |
| 原料瓶砖运输（125 t·km） | 150.0 | 150.0 |
| 生产电力消耗（850 kWh） | 467.5 | **25.5** |
| 热洗蒸汽能耗（2.0 GJ） | 130.0 | 130.0 |
| 氢氧化钠药剂（15 kg） | 31.5 | 31.5 |
| 新鲜水消耗（2.5 m³） | 0.95 | 0.95 |
| 污水处理（2.2 m³） | 6.05 | 6.05 |
| 副产 HDPE 替代信用 | −150.0 | −150.0 |
| **净生命周期碳足迹** | **636.0** | **194.0** |

$$
\text{GWP}_{\text{green}} = 150.0 + 25.5 + 130.0 + 31.5 + 0.95 + 6.05 - 150.0 = \mathbf{194.0\ \text{kg CO}_2\text{e/t}}
$$

### 3. 减碳幅度核算

较石化原生 PET 基准（2,250 kg CO₂e/t）：

$$
\text{相对减排率}_{\text{green}} = \frac{2{,}250.0 - 194.0}{2{,}250.0} \times 100\% = \mathbf{91.4\%}
$$

> **结论**：绿电驱动将净碳足迹从 636.0 进一步压降至 194.0 kg CO₂e/t（再降 69.5%），相对原生 PET 的减排幅度由基线 71.7% 大幅提升至 **91.4%**。电力分项从“第一大排放源”（占 73.5%）降为次要分项，运输成为绿电情景下的主导排放源。

## 三、任务 1.2 —— TEA 平准化成本“绿电溢价”核算

### 1. 成本变化计算

| 参数 | 基准 | 绿电情景 | 变化 |
| :--- | :---: | :---: | :---: |
| 购电单价 | 0.65 元/kWh | **0.70 元/kWh**（+绿色溢价 0.05） | +0.05 |
| 电力动力成本（吨产品） | 552.5 元/t | **595.0 元/t** | +42.5 元/t |

$$
\text{电力成本}_{\text{green}} = 850\ \text{kWh} \times 0.70\ \text{元/kWh} = 595.0\ \text{元/t}
$$

$$
\text{LCOP}_{\text{green}} = 6{,}153.4 + 42.5 = \mathbf{6{,}195.9\ \text{元/t}}
$$

$$
\text{成本增幅} = \frac{42.5}{6{,}153.4} \times 100\% = \mathbf{0.69\%}
$$

### 2. 经济可行性影响

| 指标 | 基准 | 绿电情景 |
| :--- | :---: | :---: |
| LCOP | 6,153.4 元/t | 6,195.9 元/t |
| 吨产品税前毛利（售价 7,600） | 1,446.6 元/t | 1,404.1 元/t |
| 毛利降幅 | — | 仅 2.9%（42.5 元/t） |

### 3. “绿色低碳溢价”定价与营销策略建议

- **成本侧**：绿电投入使 LCOP 仅上升 42.5 元/t（增幅 0.69%），几乎无财务阻力。
- **碳价值侧**：等量投入换来净碳足迹 636 → 194 kg CO₂e/t 的跃迁，具备极高的单位减碳性价比（约 0.096 元/kg CO₂e 减碳成本）。
- **定价建议**：将“100% 绿电”打造为产品差异化卖点，对外征收**绿色低碳溢价**。盈亏平衡所需溢价仅 42.5 元/t（约 0.6%）；而国际饮料品牌为兑现 Scope 3 减排承诺、获得 RE100/绿色电力证书背书并用于碳中和产品营销，通常愿意支付 **3%～8%** 的绿色 rPET 溢价。建议挂牌价 $7{,}600 \times (1 + 3\%\sim 8\%) \approx 7{,}828 \sim 8{,}208\ \text{元/t}$，在完全覆盖绿电增量成本的同时，将环保溢价转化为超额利润，形成“绿色溢价 > 绿色成本”的良性商业闭环。

## 四、任务 1.3 —— 源头敏感度分析（收率 80% → 70%）

> 情景：城市垃圾分类不完善，进厂瓶砖杂质率上升，综合产品收率由 80% 降至 70%。

### 1. 物耗系数的连锁放大

$$
\text{单吨产品物耗} = \frac{1}{0.70} = \mathbf{1.4286\ \text{t 瓶砖/t rPET}}\quad(\text{原 } 1.25，\text{放大 } +14.29\%)
$$

### 2. 对 LCA 碳足迹的连锁效应

| 分项 | 基准 (kg CO₂e/t) | 收率 70% (kg CO₂e/t) | 方向 |
| :--- | :---: | :---: | :--- |
| 原料运输（随瓶砖量等比放大） | 150.0 | 171.4 | ↑ +21.4 |
| 副产 HDPE 信用（随回收量等比放大） | −150.0 | −171.4 | ↓ 抵扣增大 21.4 |
| 其余公用工程（吨产品定额，暂不变） | 336.0 | 336.0 | 持平 |
| **净碳足迹（仅物耗放大下限情景）** | **636.0** | **≈636.0** | 基本持平 |

> **关键洞察**：在“仅物耗放大”的简化工况下，运输负担增加（+21.4）与 HDPE 副产信用增加（−21.4）**恰好相互抵消**，净碳足迹几乎不变。但这是“副产品配额法（Avoided Burden）”导致的**账面对冲现象**，并不代表环境负担真的降低。
>
> **现实情景下净碳足迹将抬升**：杂质率上升通常迫使预处理、分选、清洗环节强化运行（电力/蒸汽/药剂/水耗上升），并产生更多难以用副产品抵扣的固废处置负荷，这些都会使 LCA 净碳足迹在 636 kg CO₂e/t 基础上进一步攀升，直接削弱对标原生 PET 的“绿色卖点”。

### 3. 对 TEA 成本的连锁效应（量化）

| 分项 | 基准 (元/t) | 收率 70% (元/t) | 变化 (元/t) |
| :--- | :---: | :---: | :---: |
| 原料废瓶砖费用 $1.4286 \times 4200$ | 5,250.0 | 6,000.1 | **+750.0** |
| HDPE 副产收入抵扣 $0.10714 \times 4500$ | −421.9 | −482.1 | −60.2 |
| 焚烧固废处置费 $0.0929 \times 250$ | 20.3 | 23.2 | +2.9 |
| 其余成本（电力/蒸汽/人工/折旧等，吨产品定额） | 1,305.0 | 1,305.0 | 持平 |
| **LCOP** | **6,153.4** | **≈6,846.1** | **+692.7（+11.3%）** |

> 附：HDPE 单吨产出 = $1.4286 \times 0.075 = 0.10714\ \text{t}$；焚烧固废 = $1.4286 \times 0.065 = 0.0929\ \text{t}$。

$$
\text{吨产品毛利}_{70\%} = 7{,}600 - 6{,}846.1 = \mathbf{753.9\ \text{元/t}}\quad(\text{原 } 1{,}446.6，\text{腰斩约 } 47.9\%)
$$

### 4. 跨维联动结论

收率从 80% 跌至 70% 时，前端源头杂质的变化沿“**物耗放大 → 原料采购成本激增 → LCOP 走高 → 吨产品利润腰斩**”链条传导，对回收企业的生存能力（TEA）造成远大于环境账目（LCA）的冲击。这印证了讲义的核心教学点：**不建立在物质平衡（MFA）基础上的绿色规划只能是纸上谈兵**，垃圾分类源头纯度是环境足迹与经济可行性的共同前提。
