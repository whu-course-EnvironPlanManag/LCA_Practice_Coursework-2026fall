## 新增资料能补什么

### 1. M02黑粉捕集率有实验代理

[Yingnakorn等2026，Table1](https://www.sciencedirect.com/science/article/pii/S258900422603110X)给EV模块RouteEV I捕集率0.9328（原93.28%，3次独立实验SD=0.0405），分母为同源手工拆解可回收黑粉，不是整包或Li。RouteEV II为0.8353，另列不平均。借用于LFP和本园区规模，是工程迁移假设；实际厂测仍null。未捕集部分需追踪，不全记排放或危废。论文已在2026-11-03前发表。

### 2. LS23同源粉料路线补到了水分、产品和分线用水

[朗赛环评](https://hbj.yueyang.gov.cn/uploadfiles/202312/2023120609494581990.pdf)表3.4-1（印刷p65/PDF77）给粗Li2CO3含水0.20、干纯度0.99；FePO4渣含水0.40、干纯度0.99。二者内部去下游，不是已获电池级销售规格的成品。表3.5-4（p76/PDF88）列粉料H2O=0.0215；其他元素干湿基仍需明确，不能把组成总和归一化。

给IDE的LS规模示例以9,418.856t/a作为粉料投料量级，另假定进料达到LS同源质量。这**没有证明JR产粉与LS入料匹配**，因此不闭合整包Li，也不转正式全厂清单：

| LS独立条件路线 | 年量 | 单位/说明 |
|---|---:|---|
| 粗Li2CO3中间品湿质量 | 1,338.051 | t/a，含水20% |
| 其中干纯Li2CO3 | 1,059.736 | t/a，非已精制电池级可售量 |
| FePO4渣湿质量 | 7,060.243 | t/a，含水40% |
| 其中干纯FePO4 | 4,193.784 | t/a，非最终产品 |
| 外供纯水 | 3,288.247 | m3/a，不与同量制水原水重复 |
| 蒸汽 | 11,065.041 | t/a，状态未核不转MJ |
| 98%硫酸，总表版本 | 5,303.312 | t商品/a |
| 32%液碱 | 13,788.612 | t商品/a |

JSON还列出补水、冷凝水外排、酸雾/清洗废水、分线一般固废及预处理天然气/氮气。不同处理层级分开，不把LFP所有残渣统称危废。原生电芯线还可推导目标粉组分捕集0.989796，但其分母与EV I不同，不能相互平均或替代元素Li回收。

硫酸0.5630527和0.4902t98%酸/t粉料分别来自原辅料表和稀释酸雾核算，冲突保留。采购清单参考前者较合适，后者作独立敏感性，不能断言原文某处必错。组合电耗11,232,000kWh/a包含10,000t电芯、10,000t粉料及公辅，独立湿法电耗仍null。

LS表间推导Li进入粗碳酸锂比例约0.874978，受同表质量基假设限制；它与另一文献的浸出0.976或“回收>0.90”不是同一指标。粉回收工程分析§4.2.3（p97/PDF109）公开版标保密，逐工段分配无法由公开表补齐。

### 3. 三元可补一套独立通用模型活动量

[ANL EverBatt2019](https://publications.anl.gov/anlpubs/2019/07/153050.pdf)表10按电芯而非整包给电/天然气/柴油/水及六类试剂。补充JSON保留原系数，并按本组15,104.908t/a三元电芯年化为**独立参考**。商业浓度未交代的试剂没有被擅自换成98%酸或某浓度液碱。表12的Li0.90、Ni/Co/Mn0.98等是全路线默认，不能再乘独立黑粉损失后仍声称是同一总回收率。没有配套完整成品规格，不直接提供可售盐吨数。

### 4. 现有中试文献应纠正收率含义

[江洋等2024](https://hgxb.cip.com.cn/CN/10.11949/0438-1157.20240004)表6粉料输入Li87.8kg，进入Li2CO3为71.8kg、进入Li3PO4为10.4kg；Li2CO3去向比约0.817768。表2的0.976是煅烧后浸出率。表7已有2t粉料对应的产品和物耗，不必重搜，但不能把该中试产率直接嫁接给JR/LS不同品位粉料。循环洗水Li不能在外部产品中再记一次。原文99.94%闭合也不自动满足本组严格小于0.0005的平衡误差要求。

### 5. 国内标准与当前政策

电池级碳酸锂应核[YS/T582-2023官方目录](https://std.samr.gov.cn/hb/search/stdHBDetailed?id=1C51E7879EF6D54EE06397BE0A0A1DC6)，已替代2013版；FePO4核[HG/T4701-2021](https://std.samr.gov.cn/hb/search/stdHBDetailedCNF?id=D7B6988FD9D1AABEE05397BE0A0A1B36)。目录状态已经核实，完整质量指标及本厂检测未齐，不能因计划生产就认定达标。

[工信部2026年第20号公告](https://www.miit.gov.cn/jgsj/jns/wjfb/art/2026/art_945f3df30a984763877679740ff296a3.html)已改变原梯次利用公告管理；再使用产品仍需对应应用质量证据，禁止用于电动自行车等禁止领域。C保留质量指标缺失时UNKNOWN的处理可继续使用。此处不推定本案例产品具有可售资格。
