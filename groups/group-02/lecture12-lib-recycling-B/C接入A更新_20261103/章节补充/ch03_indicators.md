# 第3章 规划目标与量化指标体系

> 当前版本：A补充接入v2，见report/a_update_20261103/C年度清单接续报告.md；旧阶段数字保留历史含义，正式LCOR仍未就绪。

本章针对宜昌高新区退役动力电池循环经济产业园规划仿真案例，以2026年为基准年、2030年为近期、2035年为远期，围绕资源回收、能源与降碳、污染控制及水效建立指标。设计进料能力为8万吨/年电池包，其中1万吨与7万吨分别为再次使用、拆解再生的满负荷包当量预算。收到经济表另设85%负荷、即6.8万吨/年实际进料情景，实际分支流量须由A确认，不将设计预算直接作为实际年处理量。实际模组、电芯及产品量需依据物质流核算。

## 3.1 目标设定与口径

指标分为任务书要求筛选的约束性指标与小组提出的预期性指标。以下约束性分类用于课程规划评价，不能据此认定全部指标均为所有企业的普遍法定许可要求。正式报告应逐项核实文件性质、适用对象、有效版本及核算方法。

同一方案应使用相同统计期。设计能力、实际处理量、收集率、预处理回收率、冶炼段回收率和产品中再生含量分别核算。元素质量以取样检测和质量台账为依据；不能把电池总质量作为元素回收率分母。

## 3.3 监测和评价

**2026-11-03原文核对更新：** 已核读[工信部2024年第42号公告所附正式PDF](https://www.miit.gov.cn/cms_files/filemanager/1226211233/attach/202410/8cee9eb9b5af4f7a8bb05880e552ac66.pdf)，12项国内数值规则已登记页码与条款，见`data_cohort/policy_evidence_register.csv`。铜铝回收率与固氟率三项未在本次核读的规范正文中确认该阈值，继续作为任务书要求单列，不能称为该规范已核验条款。规范自身说明其为行业引导文件、非行政审批前置条件；产能要求含原则性表述，不能将所有阈值一律解释为普遍法定义务。上表来源说明据此更新，欧盟整合版本及全部配套条款仍待完整核验。

A负责物料及计量边界，B负责环境因子和排放核算，C维护政策版本、经济口径及筛选规则。每个方案保留输入、规则版本、判定结果和不通过原因。缺失值返回UNKNOWN，在补齐证据前不进入推荐方案集合；FAIL方案保留用于解释约束影响，不能从扫描记录中删除。

对同时包含冶炼与材料修复的园区，应分别核算分支指标。修复产品质量与市场接受条件需另行验证，不能仅因材料回收率达标就假设全部产品按新品价格出售。近期、远期的最终目标由B的可行方案结果和A的工程能力支撑，C负责核对其政策与经济一致性。

## 3.4 已接收工况的指标证据审查

对B提交的3267组占位工况独立复算后，原两规则筛选2970组通过、297组未通过。原筛选不包含工艺废水回用、材料修复目标材料回收、粉料杂质及完整项目许可等证据，因此不将2970组称为已确认合规方案。

采用本章较完整的国内课程指标和保守工艺映射后，99组纯湿法占位工况因折标能耗超值形成诊断FAIL，其余3168组为UNKNOWN，没有可据现有证据直接判为完整PASS的工况。混合或直接修复缺少产品分支及功能分母，不能用总活动量直接证明每吨碳酸锂能耗；B的线性总收率也不能替代分支收率。

2026年7月30日[工信部第20号公告](https://www.miit.gov.cn/jgsj/jns/wjfb/art/2026/art_945f3df30a984763877679740ff296a3.html)已废止2024年本中“梯次利用”有关条款。1万吨再次使用能力及满负荷分流预算继续作为规划情景，其应用类别、适用质量标准和符合性证据需独立审查，不能引用旧梯次能力门槛证明合规。该结论不意味着所有再次使用方式均被禁止。

逐项结果见 `data_cohort/integration_20261103/policy_checks_diagnostic.csv`；上述为占位工况诊断，不是对实际企业违法情况的认定。
