## 5.1 功能单位与系统边界

- **功能单位**：1 t 电池级碳酸锂（Li₂CO₃）当量（LCE）。
- **系统边界**：摇篮到大门（Cradle-to-Gate），覆盖收集运输 → 放电拆解 → 机械破碎分选 →
  精炼再生（湿法冶金 / 直接正极再生）→ 污染治理五段。
- **多产品分配**：电池级 Li₂CO₃ 主产品承担 100% 负荷；镍钴锰盐、磷酸铁、铜铝箔等副产按
  avoided burden（系统性替代原生开采）逻辑折减。该分配口径为占位，待成员 A 物料衡算校准。

## 5.2 LCA 清单与原生矿产基准

单位活动量环境因子存于 `data_cohort/environmental_factors.csv`，分为电力、热能、化学试剂、
运输与污染治理五类，逐条标注出处。区域电网水因子随碳强度档位同步变化
（低碳 0.314→1.50 L/kWh、全国基准 0.556→2.00 L/kWh、高碳 0.749→2.50 L/kWh），
确保区域电源结构差异同时进入碳排放与水资源消耗核算。

原生矿产基准（1 t Li₂CO₃）取公开 LCA 文献量级：

| :--- | ---: | ---: |
| 盐湖卤水提锂 | 4,000 | 470,000 |
| 硬岩锂辉石提锂 | 9,000 | 170,000 |

## 5.4 多情景仿真

决策变量（规划可控）：园区绿电消纳比例 `green_ratio ∈ [0,1]`（11 档）、直接正极再生占比
`process_mix ∈ [0,1]`（11 档）。外部情景（与决策变量分离）：区域电网碳强度
`grid_ef ∈ {0.314, 0.556, 0.749}`、碳酸锂价格 `lithium_price_usd ∈ {10000, 22000, 50000}`、
工艺能效等级 `energy_efficiency ∈ {0.80, 1.00, 1.20}`。笛卡尔积共 3,267 组工况
（≥500，达标），结果存于 `data_cohort/scenario_results.csv`。

| 指标 | 范围 |
| :--- | ---: |
| GWP100 | 2,538 ~ 17,283 kg CO₂e/t |
| 水耗 | 13,097 ~ 83,876 L/t |
| 锂回收率（占位映射 0.90+0.09·pm） | 0.90 ~ 0.99 |

水耗—碳排放权衡关系见图 B-2（[fig_b2_water_carbon_tradeoff.png](../figures_output/fig_b2_water_carbon_tradeoff.png)），

## 5.5 敏感性分析

以 GWP100 为目标的单因素敏感性摆幅（全工况，按参数各水平均值极差）见图 B-3
（[fig_b3_sensitivity.png](../figures_output/fig_b3_sensitivity.png)）。主导变量依次为
`process_mix`（5,129.0）、`green_ratio`（4,668.2）、`grid_ef`（2,011.9）、
`energy_efficiency`（1,398.5）；`lithium_price_usd` 为经济变量，对 GWP100 影响为零（符合预期）。
工艺配比与绿电比例为环境端主导变量，与任务书「再生精炼电力消耗占碳足迹主导」的设定一致。
