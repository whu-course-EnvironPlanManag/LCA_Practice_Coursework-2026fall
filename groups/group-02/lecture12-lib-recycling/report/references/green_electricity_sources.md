## 1. 结论先行：绿电比例的两类含义

绿电比例必须区分「**求解结果**」与「**目标约束**」，两者不能混用：

| 类别 | 规则 | 结果 | 是否「最优」 |
| :--- | :--- | :---: | :--- |
| A 原丰枯期组内假设 | 丰水期(6—10月，5个月)覆盖 1.00；枯水期(11—次年5月，7个月)覆盖 0.35 | 62.08% | 历史假设，**非最优** |
| B1 成本最优·绿电供应/合同不受限 | 恒定价格下绿电(0.51) < 网电(0.62)，成本随绿电单调下降 | 100% | **成本最优（价格求解）** |
| B2 成本最优·仅水电（季节形状 R3–R6） | 各季用满水电合同上限（全年水电合同 = 年用电 60%，情景假设） | 59.99% | 条件最优（情景；合同水平未定） |
| C 年度目标 80% 下最低成本 | 在绿电<网电下，达标即用足 80% | 80% | **外生目标约束**，非求解最优 |
| D 成本—碳排放（R7 因子） | 未设碳价/权重，不构造联合优化 | — | 权衡（未设权重），不产生「唯一最优比例」 |

- 62.08% 的来源是 **5/12×1.00 + 7/12×0.35 = 0.620833**，这是组内供给假设下的按月数加权，**不是**基于真实市场数据求解。
- 原枯水期 65.71% 是 **（0.80×12−5）/7 = 0.657143**，这是 80% 年度目标的反推值，**不是**枯水期最优覆盖比例。本次已从模型中移除该反推，仅作历史对照说明。
- 年度绿电比例一律用**电量加权**：`annual_green_ratio = Σ(合格绿电量 kWh) / Σ(园区用电量 kWh)`；不默认按月数加权（等月/季度用电仅为显式情景假设，因无园区分月负荷数据）。

## 3. 环境权益的三层口径（R1 第98条、R2 第16/24/31条）

为避免同一 kWh 重复计环境权益，应分别登记（本模型因缺数据仅显式保留第一层并作边界约束，后两层标记为「未取得」）：

1. **对应物理供电或合同匹配的绿色电量** —— 模型可据价格与合同上限情景化计算；
2. **可归属园区并完成相应确权的绿色电量** —— 依赖 R2 绿证确权路径，未取得园区真实确权数据；
3. **另购绿证覆盖的消费电量** —— 本研究允许该路径，但未设置绿证价格/数量，标注「未取得」。

同一 kWh 不重复计算环境权益；不把电网本身水电占比直接计为园区新增采购绿电。

## 5. 仍缺失的实际数据

- 园区分月用电量 / 分月合同电量（无 → 等季用电仅为情景假设）；
- 实际到户成交价（网电、绿电、环境权益分开的价格，未取得原件）；
- 全年水电可签约量 / 风光可采购上限（B2 仅用 60% 方法演示值）；
- 偏差、补购与保供成本；
- 绿证价格与可另购数量；
- 宜昌/湖北本地月度碳足迹因子（现用 R7 全国年度因子代理）。

> 综上，输出仅表述为「条件最优／情景结果」，不宣布「宜昌唯一最优绿电比例」。
