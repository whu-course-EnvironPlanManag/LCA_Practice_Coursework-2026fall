## 二、LCA 模型（`lca_model.py`）

### 2.1 功能单位与系统边界

- 功能单位：1 t 电池级碳酸锂（Li₂CO₃）当量。
- 系统边界：摇篮到大门，覆盖收集运输、放电拆解、机械破碎分选、精炼再生（火法/湿法/
  直接再生）与污染治理；再生 Li₂CO₃ 主产品承担 100% 负荷，副产镍钴锰盐/磷酸铁按
  系统扩展折减逻辑处理（占位，待成员 A 物料衡算校准）。

### 2.2 环境因子与原生基准

- 环境因子存于 `data_cohort/environmental_factors.csv`，含电力（绿电/全国/高碳/低碳网电）、
  热能、化学试剂、运输与污染治理五类，逐条标注出处。
- 区域电网水因子随碳强度档位同步变化（`grid_low_carbon` 0.314→1.50 L/kWh、
  `grid_china_base` 0.556→2.00 L/kWh、`grid_high_carbon` 0.749→2.50 L/kWh），
  避免固定水因子导致区域变化未进入水耗的问题。
- 原生矿产基准（1 t Li₂CO₃）：盐湖卤水提锂 GWP 4000 kg CO₂e、水耗 470,000 L；
  硬岩锂辉石提锂 GWP 9000 kg CO₂e、水耗 170,000 L（文献 1 及其开源数据量级）。

### 2.3 自检结果（基准占位活动量，绿电比例 80%）

| 指标 | 数值 |
| :--- | ---: |
| 净 GWP100 | 6,709.2 kg CO₂e/t Li₂CO₃ |
| 净水耗 | 50,180.8 L/t（50.2 m³/t） |
| 相对盐湖卤水基准减排 | −2,709.2 kg CO₂e/t（−67.7%） |
| 相对硬岩锂辉石基准减排 | +2,290.8 kg CO₂e/t（+25.5%，占位活动量下 GWP 高于该基准） |

> 占位活动量下净 GWP 偏高的主因是试剂上游隐含负荷与高电耗，正式结论须待成员 A
> 工序级活动量替换后重新核算，上述数值仅为模型可运行性自检，不作为最终结果引用。

## 三、多情景仿真（`scenario_analysis.py`）

### 3.1 变量设定

- 决策变量（规划可控）：园区绿电消纳比例 `green_ratio ∈ [0,1]`（11 档）；
  直接正极再生占比 `process_mix ∈ [0,1]`（11 档，0=纯湿法，1=纯直接再生）。
- 外部情景（与决策变量分离）：区域电网碳强度 `grid_ef ∈ {0.314, 0.556, 0.749}`；
  碳酸锂价格 `lithium_price_usd ∈ {10000, 22000, 50000}`；工艺能效等级
  `energy_efficiency ∈ {0.80, 1.00, 1.20}`。

### 3.2 仿真规模与结果

| 项目 | 数值 |
| :--- | ---: |
| 总工况数 | 3267（≥500 达标） |
| GWP100 范围 | 2,538.2 ~ 17,282.8 kg CO₂e/t Li₂CO₃ |
| 水耗范围 | 13,097.0 ~ 83,875.8 L/t |
| 锂回收率范围（占位映射 0.90+0.09·pm） | 0.90 ~ 0.99 |
| 政策引擎判定 | PASS 0 / FAIL 99 / UNKNOWN 3168 |
| 可行工况（`feasible`） | 0 |
| LCOR（成员 C TEA 未就绪） | 全部 NaN |

政策引擎当前 `UNKNOWN` 占主导，原因为混合工艺分支级回收率、粉料杂质、氟固化、水回用
及能耗分母等判据需成员 A 的工序级数据补入后方可判定；`FAIL` 项集中于吨 LCE 综合能耗
超阈值（`CN_ENERGY`）占位值。上述为联调诊断状态，不代表规划园区的实际合规结论。

## 四、环境维度敏感性分析

以 GWP100 为目标的单因素敏感性摆幅（全工况，按各参数水平均值极差）：

| 排序 | 参数 | GWP100 摆幅（kg CO₂e/t） |
| :---: | :--- | ---: |
| 1 | `process_mix`（直接再生占比） | 5,129.0 |
| 2 | `green_ratio`（绿电比例） | 4,668.2 |
| 3 | `grid_ef`（电网碳强度） | 2,011.9 |
| 4 | `energy_efficiency`（能效等级） | 1,398.5 |
| 5 | `lithium_price_usd`（碳酸锂价格） | 0.0 |

碳酸锂价格为经济变量，不影响 GWP100（符合预期）；工艺配比与绿电比例为环境端主导变量，
与任务书「再生精炼电力消耗占碳足迹主导」的设定一致。
