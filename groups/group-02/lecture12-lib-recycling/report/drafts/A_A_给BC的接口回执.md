### 1.2 B 使用这 12 键时必须遵守的 5 条

1. **不得把年度量除以粉量或 LCE 造 per-FU**：A 的 LCE 产量本身未解锁（`GAP-LCE-SALE`），分母不存在。
   B 的 12,000 MJ/t、2,500 kg/t 等占位值分母是 **B 自己的 6.0969 t 粉料/t LCE**，与 A 的年度量不是同一分母。
2. **不得把一个键的年度量代入另一个键的 per-FU**：例如用 11,232,000 kWh/a ÷ 粉料量得出的"电耗"是**组合电耗人造分摊**，
   A04 已明确禁止（ND22 综合能耗 − LS 蒸汽 = 电 的换算也一并删除）。
3. **单位原样传递**：蒸汽只给 **t**（不转 MJ，压力/温度/返凝水未核）；天然气只给 **Nm³**（未折 MJ）；
   双氧水与碳酸钠来自 **JIANG24 中试**，不是 LS 原表系数，只能作量级参照。
4. **商品吨与有效吨必须成对引用**：32% 液碱 13,788.612 t 商品 = 4,412.356 t 有效 NaOH；
   98% 硫酸 5,303.312 t 商品 = 5,197.246 t 有效；92% 氧化钙 276.914 t 商品 = 254.761 t 有效。
   若 B 的因子按"纯物质"给，必须用有效吨；按"商品"给，必须用商品吨。**混用会使结果偏差 3%—68%**。
5. **不平均、不拼线**：`b_activity_reference_profiles.csv` 的 78 行按 `profile_id` 隔离
   （LS23 38 行 / ANL19 18 行 / JIANG24 18 行 / ND22 4 行），**禁止把多个 profile 拼成一条产线**；
   EV I（0.9328）与 EV II（0.8353）捕集率并列，禁止取均值。

### 6.3 B / C 读 R1 表必须遵守的纪律

1. 每条 R1 数据都带 `attribute`（组内设定 / 文献原值 / 文献迁移 / 情景假设 / 无），引用时必须连标签一起写，不得当成实测值。
2. **可售品仍为 null**：粗碳酸锂、磷酸铁渣、Ni/Co/Mn/Cu/Al 元素量、纯 Li₂CO₃ 当量都不是合格商品（`GAP-LCE-SALE` 未解）。
3. **0.50 是 t 总粉/t 电芯产率，不是黑粉捕集率**（`M02_ACTUAL` 仍缺失）；**622/811 是技术端点，不是本地拆分**（`D06-NMC` 仍缺失）。
4. 硫酸主 6,781.30 / 备选 5,903.88 **并列不平均**；蒸汽 14,148.77 t **不转 MJ**；组合电耗是 α=0.50 **分摊假设**，不分线拆。
5. `dmfa_r1_future_*`（未来新增首装+替换）与 `dmfa_yichang_*`（既有队列剩余释放）**不可相加**；
   2040 收集 27,640.36 = 退出 34,550.45 × 0.80，供需量比 40.65% 只是**条件供需量比，不是园区进料**。
