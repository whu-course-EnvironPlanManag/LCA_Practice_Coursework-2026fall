# 案例二：绿色甲醇 MFA–LCA–TEA 计算与数据核验

**功能单位：** 1 t 聚合级甲醇。计算输入仅取自本案例[讲义](../case_files/case2_documentation.md)第一至五部分及其三个 [CSV 数据表](../case_files/data_cohort/)。运行 `mfa_lca_tea.py` 复算任务一、二，运行 `process_flow.py` 重绘任务三流程图。所用环境为 `mfa_lca_tea`。数值按计算精度输出，显示位数不代表源数据具有相同精度。

## 任务一：反应、分离与循环回路

### 1. 质量流方程与解

用 `F` 表示新鲜 CO₂ 与 H₂ 进料，`R` 为循环气，`M` 为反应器入口，`L` 为分离器液相，`G` 为分离器气相，`P` 为驰放气，`q` 为分流回流比例。稳态总质量方程为：

```text
F = 1423 + 198 = 1621 kg/t
M = F + R
反应器出口总质量 = M
G = M - L
R = qG；P = (1-q)G；G = R + P
L = 1000 + 575 = 1575 kg/t
```

| 控制体 | 输入 kg/t | 输出 kg/t | 差值 kg/t |
|:--|--:|--:|--:|
| 混合器 | 1,621 + 4,640 = 6,261 | 6,261 | 0 |
| 反应器 | 6,261 | 6,261 | 0 |
| 分离器 | 6,261 | 1,575 + 4,686 = 6,261 | 0 |
| 分流器 | 4,686 | 4,640 + 46 = 4,686 | 0 |
| 精馏塔 | 1,575 | 1,000 + 575 = 1,575 | 0 |
| 合成工段外边界 | 1,423 + 198 = 1,621 | 1,000 + 575 + 46 = 1,621 | 0 |

由 CSV **实际**数值，`R/F = 4640/1621 = 2.862431`，`q = 4640/4686 = 99.018353%`，`P/G = 0.981647%`。讲义所说循环比 **3.8:1** 不符合其“循环气量/新鲜气量”的定义；99/1 分流可以视作对实际数据的约数，但不能同时作为精确方程。若精确指定 `q=0.99`，保持 `F=1621` 与 `L=1575`，联立得 `G=(F-L)/(1-q)=4600`、`R=4554`、`P=46` kg/t，和 CSV 的循环流相差 86 kg/t。

### 2. 单程转化率与碳利用率

按 CSV 的反应器入口和出口 CO₂ 质量分数直接计算：

```text
入口 CO₂ = 6261 × 79.50% = 4977.495 kg
出口 CO₂ = 6261 × 63.10% = 3950.691 kg
表观单程转化率 = 1 - 3950.691/4977.495 = 20.6289%
```

这个表观值与标称 25% 不一致。更早一级的混合器组分也不闭合：新鲜 CO₂ 和循环气提供的已知 CO₂ 是 `1423×99.8% + 4640×75.4% = 4918.714 kg`，而 `S07` 反应器入口列出 4977.495 kg，相差 58.781 kg。`S08` 反应器出口各组分质量分数之和为 **102.4%**。因此无法从这些组分求出可信的完整化学反应进度。

若**额外假设**未反应 CO₂ 全部保留在气相、每程 25% 的 CO₂ 反应、气相中 99% 回流，可建立理想 CO₂ 子回路：

```text
R_CO₂ = 0.99 × (1-0.25) × (1423 + R_CO₂)
R_CO₂ = 4103.214 kg/t
P_CO₂ = 0.01 × 0.75 × (1423 + R_CO₂) = 41.447 kg/t
总体 CO₂ 反应率 = 1 - P_CO₂/1423 = 97.0874%
```

该子回路仅是**假设模型**，不等于 CSV 的实测流股，也不代表全部反应碳都进入甲醇。按给定产品量和讲义分子量计算的**产品碳利用率**为 `(1000/32.042)/(1423/44.01)=96.5221%`；若进一步按 CSV 的 99.9% 甲醇及 99.8% 新鲜 CO₂ 纯度修正，为 **96.6188%**。两者均不能严格验证讲义所要求的 96.0%。其中 32.042 g/mol 由 C=12.01、H=1.008、O=16.00 计算；讲义的 32.04 为舍入数。

### 3. C、H、O 元素守恒审计

对外部合成边界的 `S01`、`S02` 输入与 `S11`、`S12`、`S13` 输出，逐股用 CSV 质量和已注明的 CO₂、H₂、甲醇、水分数计算元素质量；`other_inerts_wt_pct` 的化学式未给，单列为未知。元素质量公式为 `m_{元素}=m_{物流}×w_{组分}×(该组分内元素原子质量/分子量)`。

| 元素 | 已知输入 kg | 已知输出 kg | 输入减输出 kg | 占已知输入 |
|:--|--:|--:|--:|--:|
| C | 387.549410 | 384.052976 | +3.496434 | 0.9022% |
| H | 198.141650 | 200.222739 | −2.081089 | 1.0503% |
| O | 1033.885940 | 1035.666285 | −1.780345 | 0.1722% |

未知组分质量仅有**输入 1.423 kg、输出 1.058 kg**。仅碳一项就需要未知输出比未知输入多带出 3.496 kg C，而未知输出全部质量也只有 1.058 kg；无论把未知组分解释成何种物质，都无法闭合。氢的已知输出也比已知输入多 2.081 kg，超过未知输入的全部 1.423 kg。故在**不修改源数据**的前提下，任务要求的三元素差值均低于 0.01% **不可实现**，不能打印虚假的“通过”。

为展示矛盾，若把 `S01=1423 kg` 纯 CO₂、`S02=198 kg` 纯 H₂、`S12=1000 kg` 纯甲醇、`S13=575 kg` 纯水作为名义流，并**反推**驰放气恰由 CO₂、CO、H₂ 组成，则元素恰好守恒所需驰放组成是 **CO₂ 18.374 kg、CO 19.804 kg、H₂ 7.822 kg**（合计 46 kg）。这不是观测值：CSV 对 46 kg 驰放气标称的 CO₂ 和 H₂ 已分别为 **34.684 kg** 与 **10.028 kg**，且 CO 未单独定量。反推结果不可替换为测量数据。

电解水子系统还有独立的边界缺口：`S04` 列总进水 1960 kg，制得 H₂ 198 kg 与 O₂ 1584 kg，对应理论耗水 1782 kg，余 **178 kg** 水没有在 CSV 中列出出口。这不影响上文只把 H₂ 作为合成工段外部进料的总质量闭合，但阻止整个 CO₂–水–甲醇一体化系统的严格全元素核算。

## 任务二：LCA、TEA 与电价敏感性

### 1. LCA 复算

用电清单求和为 `10296+255+155+120=10826 kWh/t`。非电净项按 **CSV 已给的带符号 GWP** 求和：直接逸散 `+15`、基础设施 `+80`、捕集碳信用 `−1423`、副产氧信用 `−95.04`，合计 **−1423.04 kg CO₂e/t**。CSV 把两个信用的实物量与因子都写为负数，直接相乘会造成符号反转；这里采用其明确列出的 GWP 信用符号。

```text
GWP(EF) = 10826×EF − 1423.04  [kg CO₂e/t]
100% 风光绿电：EF=0.035 → GWP = −1044.13 kg CO₂e/t
区域工业电网：EF=0.550 → GWP = +4531.26 kg CO₂e/t
```

绿电相对煤制甲醇 `2600 kg CO₂e/t` 的减排量为 `2600−(−1044.13)=3644.13 kg = 3.64413 t CO₂e/t`，减排率 `140.16%`。工业电网比煤制基准增加 `4531.26−2600=1931.26 kg`，即 `74.28%`。绿电结果比 CSV 的 `−1044.12` 相差 **0.01 kg**，来自逐电力子项先四舍五入至两位的加总；用电量乘原始因子得到 `−1044.13`。该 LCA 信用仅适用于讲义给定的**生产端边界和抵扣假设**；甲醇后续燃烧或氧气替代是否兑现没有纳入计算，不能把负值解释为永久封存。

### 2. TEA 成本模型与 MAC

资本回收系数 `CRF=0.08(1.08)^20/[(1.08)^20−1]=0.101852209`。资本年金分摊为 `8.20×10⁸×CRF/100000=835.188 元/t`。非电净成本核对：

```text
835.188（资本）+1423/1000×260（CO₂ 捕集）
+65（水与催化剂）+285（运维）−1584/1000×200（氧气外售）
=1238.368 ≈ CSV 所用 1238.37 元/t
```

沿用 CSV 的 `1238.37` 以复算其敏感性表，设电价 `p` 元/kWh、煤制甲醇售价基准 2500 元/t：

```text
LCOM(p) = 10826p + 1238.37             [元/t 甲醇]
绿色溢价(p) = LCOM(p) − 2500           [元/t 甲醇]
MAC_green(p) = 绿色溢价(p) / 3.64413   [元/t CO₂e]
```

| 电价元/kWh | LCOM 元/t | 溢价 元/t | 100% 绿电下 MAC 元/t CO₂e |
|--:|--:|--:|--:|
| 0.05 | 1779.67 | −720.33 | −197.67 |
| 0.15 | 2862.27 | 362.27 | 99.41 |
| 0.35 | 5027.47 | 2527.47 | 693.57 |
| 0.60 | 7733.97 | 5233.97 | 1436.28 |

折线由 0.05 至 0.60 元/kWh 按 0.001 步长绘制，使用 Plotly 导出：[SVG 矢量图](electricity_sensitivity.svg) · [高清 PNG](electricity_sensitivity.png)。CSV 每个电价点的 LCOM 与 MAC 均经程序断言复核。**MAC 分母采用绿电的净减排量**；若 0.55 元/kWh 购买的是该 CSV 的区域工业电网电，其 GWP 高于煤制基准，属于增排情景，不能沿用此正向减排 MAC。

### 3. 100 元/t CO₂e 假设碳价下的临界电价

若每吨甲醇的 `3.64413 t CO₂e` 减排都能按讲义假设的 **100 元/t CO₂e** 兑现收入，则商业平衡条件为 `LCOM(p)−2500 ≤ 100×3.64413`：

```text
p_max = [2500 + 100×3.64413 − 1238.37]/10826
      = 0.150198 元/kWh ≈ 0.1502 元/kWh
```

不计任何碳收入的成本平价电价为 `(2500−1238.37)/10826=0.116537 元/kWh`。**0.1502 元/kWh 是条件阈值，不是实时电价或政策保证**；是否有合格、可出售的减排量以及能否获得 100 元/t 收入，需另行核定。

## 课堂规划研讨：屋顶光伏与煤电混供

年产 10 万 t 所需电量为 `10826×100000=1.0826×10⁹ kWh`；若 8000 h 稳定运行，平均总负荷 **135.325 MW**，其中 PEM 年均约 `10296×100000/8000=128.7 MW`。一套 130 MW、年利用 1200 h 的光伏最多发 `130000×1200=1.56×10⁸ kWh/年`，仅占全年用电 **14.41%**，且夜间和阴雨时段仍需其他电源或储能。若仅靠这 1200 h 满发时段运行，产能利用率约 15%，相同固定 CAPEX 分摊到单位产量约增加到 `8000/1200=6.67` 倍；实际启停与储能成本未量化。按全年电量粗算，100% 光伏需约 **902 MW** 装机，仍需要时序匹配与稳定供电方案。

设全年电量中的光伏份额为 `x`。按讲义的煤电和光伏因子 `0.75`、`0.04 kg CO₂e/kWh`，且沿用其捕集/氧气等净抵扣：

```text
EF(x) = 0.04x + 0.75(1−x) = 0.75−0.71x
GWP(x) = 10826(0.75−0.71x)−1423.04
GWP(x) ≤ 2600  →  x ≥ 0.532945 ≈ 53.29%
```

该最低光伏份额对应年发电约 `0.532945×1.0826 TWh = 0.577 TWh`，按 1200 h 等效满发至少需约 **481 MW** 光伏装机。即使年度总量满足，仍需解决昼夜时序和连续化反应器供电。该临界点仅达到**与煤制甲醇排放相等**；严格低于煤制基准需要光伏份额略高于 53.29%。按混供电价 `0.20x+0.32(1−x)`，该点的平均电价约 **0.2560 元/kWh**，远高于上面的有条件经济阈值。
