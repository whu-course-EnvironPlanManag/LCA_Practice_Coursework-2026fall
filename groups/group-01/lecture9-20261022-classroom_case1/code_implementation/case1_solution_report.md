# 案例一作业：废弃 PET 瓶机械物理再生系统 MFA-LCA-TEA 核算

> 功能单位：生产 1 t 瓶级 rPET 颗粒（Cradle-to-Gate）
> 数据来源：`case_files/data_cohort/` 三个 CSV + 讲师讲义基准值

## 一、基准情景复核

| 指标 | 本脚本计算值 | 讲义/CSV 基准 | 结论 |
|---|---|---|---|
| 净碳足迹 GWP | 636.0 kg CO₂e/t | 636.0 | 一致 |
| 平准化成本 LCOP | 6153.5 元/t | 6153.4 | 一致（舍入差 0.1） |
| 原料投入 | 1000 kg | 1000.0 | 一致 |

物质平衡：输入 1000 kg = 输出 1000 kg，质量守恒成立。

## 二、任务 1.1 绿电情景 LCA 净碳足迹

仅电力一项的排放因子由 **0.55 → 0.03 kg CO₂e/kWh**，其余清单项不变。

| 过程分项 | 活动量 | 排放因子 | 碳足迹 (kg CO₂e) |
|---|---|---|---|
| 原料运输 | 1.25 t × 100 km | 0.12 kg CO₂e/kg | 150.00 |
| 电力（绿电） | 850 kWh | 0.03 kg CO₂e/kWh | 25.50 |
| 蒸汽 | 2.0 GJ | 65.0 kg CO₂e/GJ | 130.00 |
| 烧碱 | 15 kg | 2.10 kg CO₂e/kg | 31.50 |
| 新鲜水 | 2.5 m³ | 0.38 kg CO₂e/m³ | 0.95 |
| 污水处理 | 2.2 m³ | 2.75 kg CO₂e/m³ | 6.05 |
| HDPE 副产信用 | -93.75 kg | 1.60 kg CO₂e/kg | -150.00 |
| **净碳足迹 GWP_green** | — | — | **194.00** |

- 减排率：(2250 − 194.0) / 2250 = **91.4%**
- 较基准情景（636.0）再降 **442.0 kg CO₂e/t**，降幅 69.5%。
- 关键结论：基准情景中电力占总碳足迹 73.5%，是唯一决定性热点；绿电替换后，**运输（150.0）与蒸汽（130.0）跃升为主要排放源**，下一步减排应转向运输电动化与蒸汽电气化。

## 三、任务 1.2 绿电情景 TEA 与绿色溢价

绿电单价 0.65 → 0.70 元/kWh（+0.05 元/kWh 绿色溢价），耗电量不变。

| 项目 | 数值 |
|---|---|
| 电力成本 | 552.5 → 595.0 元/t（+42.5） |
| **LCOP_green** | **6196.0 元/t** |
| LCOP 增加额 | +42.5 元/t |
| LCOP 增幅 | +0.69% |
| 吨产品毛利（售价 7600） | 1446.5 → 1404.0 元/t |

**核心判断：成本增幅仅 0.69%，而碳足迹下降 69.5%，绿色溢价的“环境性价比”极高。**

定价与营销建议：
1. **溢价定价**：在 7600 元/t 基础上加价 1%~2%（76~152 元/t），即可完全覆盖 42.5 元/t 的绿电增量成本，并留有 33.5~109.5 元/t 的净收益。
2. **价值锚定**：对国际饮料品牌按“每吨 rPET 减少 442 kg CO₂e”出具碳足迹声明（PCF），把绿电成本转译为品牌 Scope 3 减排资产。
3. **长约锁定**：与品牌方签 3~5 年绿电 rPET 采购协议（PPA 联动），用销量确定性对冲绿电溢价波动。
4. **风险提示**：绿电溢价仅占成本 0.69%，但 rPET 售价受原生 PET（6800 元/t）价格牵制，溢价空间最终取决于品牌方的 ESG 支付意愿，而非成本本身。

## 四、任务 1.3 收率 80% → 70% 的连锁效应

收率下降意味着**每吨产品需多投入 1.1429 倍的原料**（1/0.7 = 1.4286 t 瓶砖/t rPET）。

| 指标 | 基准 Y=80% | 低收率 Y=70% | 变化 |
|---|---|---|---|
| 原料需求 | 1.25 t/t | 1.4286 t/t | +14.3% |
| GWP（主口径） | 636.0 | 726.9 | +14.3% |
| LCOP（主口径） | 6153.5 | 7032.6 | +14.3% |
| GWP（绿电叠加） | 194.0 | 221.7 | +14.3% |
| LCOP（绿电叠加） | 6196.0 | 7081.2 | +14.3% |

对照口径（公用工程按吨产品不变，仅运输与副产信用随进料放大）：GWP = 636.0 kg CO₂e/t，LCOP = 6965.8 元/t。

**连锁机理**：前端分类不纯 → 杂质率上升 → 分选收率下降 → 单吨产品原料需求上升 → 运输与预处理负荷加重（LCA 恶化），同时原料采购成本与固废处置量同步上升（TEA 恶化）。二者同向放大，说明**源头分类是同时决定环境绩效与经济性的共同杠杆**，这正是环境规划中“前端治理优先于末端补救”的量化依据。

## 五、结论

1. 绿电可把净碳足迹从 636.0 降至 **194.0 kg CO₂e/t**，减碳率由 71.7% 提升至 **91.4%**，是当前成本最低的深度减排手段。
2. 绿电溢价仅使 LCOP 上升 **0.69%**，环境收益远大于经济代价，具备商业可行性。
3. 收率由 80% 降至 70%，GWP 与 LCOP 同步恶化约 **14.3%**，源头分类质量是系统韧性的关键变量。

## 六、假设与口径说明

- 收率敏感度主口径假定：所有按吨产品计的物耗、公用工程与固定成本分摊均随收率反比变化（年进料 20,000 t 不变，年产量降至 14,000 t）。对照口径假定公用工程强度不变，结果一并列出以便比较。
- 水与烧碱采用讲义“综合定额”115.0 元/t；若按 CSV 单价直接核算为 59.25 元/t，差额为讲义归并的辅助药剂与定额调剂。
- 运输排放按 CSV 口径（0.12 kg CO₂e/kg 原料，运距 100 km）计算，与讲义 150.0 kg 一致。
- 副产 HDPE 采用避免负荷法计入 -150.0 kg CO₂e/t 信用。
