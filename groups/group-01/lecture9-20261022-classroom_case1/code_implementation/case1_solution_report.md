# 案例一 任务1 计算报告：绿电溢价与收率敏感度（MFA-LCA-TEA 联动）

## 0. 基准情景复核

- 净碳足迹 GWP = **636.0 kg CO2e/t**（讲义基准 636.0）
- 平准化成本 LCOP = **6153.4 元/t**（讲义基准 6,153.4）

## 1. 绿电情景 LCA 再核算

边界变更：电力排放因子 0.55 -> 0.03 kg CO2e/kWh，其余活动水平不变。

| 清单分项 | kg CO2e/t |
| :--- | ---: |
| 原料瓶砖运输 | +150.0 |
| 生产电力消耗 | +25.5 |
| 热洗蒸汽能耗 | +130.0 |
| 氢氧化钠药剂 | +31.5 |
| 新鲜水消耗 | +0.9 |
| 污水处理负荷 | +6.0 |
| 副产HDPE替代信用 | -150.0 |
| **净碳足迹 GWP_green** | **194.0** |

- 较基准减排：636.0 -> 194.0，下降 **442.0 kg CO2e/t（-69.5%）**
- 相对原生 PET（2,250）减碳幅度：**91.4%**（基准情景为 71.7%）

- LCOP 增加额：**+42.5 元/t**，增幅 **+0.69%**
- 吨毛利：1446.6 -> 1404.1 元/t；年增成本 68.0 万元

### 绿色低碳溢价定价与营销策略建议
1. **成本传导底线**：绿电产品售价至少应为 7642 元/t（在原 7,600 元/t 上加约 42 元/t 绿色溢价），即可完全覆盖绿电采购增量成本；
2. **价值锚定**：绿电 rPET 碳足迹 194 kg/t，较原生 PET 净减排 2056 kg/t。按全国碳市场约 100 元/tCO2e 计，每吨产品环境价值约 206 元，绿色溢价空间远大于 42 元/t 的成本上升，建议以 3%-8% 品牌溢价（约 230-600 元/t）面向国际饮料品牌签订绿色长单；
3. **认证与叙事**：配套 RE100/绿色电力证书溯源与 PCR 含量认证（食品级 rPET），以'碳足迹标签'切入品牌 Scope 3 减排采购清单，采用量价绑定阶梯合同锁定溢价。

## 3. 源头敏感度：收率 80% -> 70%（常规电网）

吨产品瓶砖物耗由 1.25 t 升至 1.429 t，通量放大系数 f = 1.1429。

| 指标 | 基准(80%) | 扰动(70%) | 变化 |
| :--- | ---: | ---: | ---: |
| LCA 净碳足迹 kg CO2e/t | 636.0 | 726.9 | +14.3% |
| 较原生PET减碳幅度 | 71.7% | 67.7% | -4.0 pp |
| TEA LCOP 元/t | 6153.4 | 6965.6 | +13.2% |
| 吨毛利 元/t | 1446.6 | 634.4 | -56.1% |

**连锁效应解读**：分类纯度下降使 MFA 物耗系数放大 14.3%，前端运输/清洗/分选的全部变动投入（含 HDPE 副产信用）同比例放大，LCA 碳足迹与 TEA 原料成本同步恶化；原料成本占 LCOP 近九成，故吨毛利被严重挤压。结论：**源头垃圾分类质量是 LCA 与 TEA 共同的第一敏感参数**，规划上应优先保障瓶砖分选纯度而非末端工艺优化。
