# 合并后的验证范围

执行`run_project.py --exploratory`重现27项模型测试、4000组条件情景、报告与跨文件检查。运行日志和机器核验记录在`../data_cohort/results/`；`validation.json`记录输入哈希、四元素收支、逐年锂流汇总、锚点与物质流/工程表、全部PNG引用及300 DPI等。

实质检查包括浮点等价方案保留、湖北直接工业取水累进税，以及新增DMFA图对应的锂流汇总：分别核对零梯次库存和期初梯次释放的守恒算例，错误的流出去向须被拒绝。逐年汇总CSV还须与原始DMFA和Li守恒表逐值一致。依然不能证明安装、寿命、工艺、报价及空间代理是真实观测，也没有代签团队确认。具体边界见`../report/Data_and_Code_Audit.md`。

正式图片目录仅保留PNG。制图时若显式设置`LECTURE12_QA_DIR`，PDF/SVG和对齐检查仅写到该外部检查目录，用于文字碰撞和字号核验；常规运行不生成多格式副本。
