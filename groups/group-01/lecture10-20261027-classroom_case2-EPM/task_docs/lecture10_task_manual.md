## 一、 实训定位与教学目标

本实训作为《环境规划与管理》课程的核心综合实践单元，旨在引导学生打破单一的“模型计算”局限，将**物质流分析（MFA）**、**全生命周期评价（LCA）**、**技术经济分析（TEA）**以及**国内外环境与双碳政策法规**有机融合，体验一份符合国家技术标准与工程可行性要求的《工业园区环境规划与管理方案报告》的完整编制技术路线。

### 核心能力培养目标

1. **系统解耦与尺度放大能力**：掌握化学反应分离循环回路中单程转化率（$25.0\%$）与系统总碳转化利用率（$96.0\%$）的解耦机制，实现单吨定额向 10 万吨/年工业园区级工程通量的科学放大；
2. **政策法规量化建模能力（Vibe Coding）**：阅读并提取真实政策法规（欧盟 RED III、国内全国碳市场 ETS/CCER、工业取水定额累进税率、次生大气污染物环保税）的定量阈值，编写 Prompt 生成政策规制引擎；
3. **多目标帕累托决策能力**：以清洁绿电消纳比例 $f_{\text{green}}$ 与循环气驰放分流比 $r_{\text{purge}}$ 为决策调控变量，求解最小化净平准化成本（LCOM）与最小化全生命周期净碳足迹（GWP）的帕累托前沿，掌握帕累托拐点（Knee Point）的标定与多方案比选；
4. **国家级环境规划报告编制能力**：严格遵循科学客观陈述原则，规范撰写包含现状诊断、规模核算、指标体系、空间落位、重点工程清单表、综合评估及制度闭环的完整六章规划报告。



## 二、 随堂演练研讨任务

* **情景设定**：某大型现代煤化工园区拟规划建设一条 **10 万吨/年** 绿氢合成绿色甲醇示范线。园区电网由两部分构成：自备燃煤电厂（供电结算价 $0.32\text{ 元/kWh}$，碳排放因子 $0.75\text{ kg CO}_2\text{e/kWh}$）与配套建设的工业级屋顶分布式光伏发电系统（年有效利用小时数 $1,200\text{ h}$，供电结算价 $0.20\text{ 元/kWh}$，碳排放因子 $0.04\text{ kg CO}_2\text{e/kWh}$）。
* **研讨任务**：
  1. **问题 1（设备负荷与利用率约束）**：为什么“屋顶分布式光伏”无法独立支撑质子交换膜（PEM）电解水制氢与甲醇催化合成装置？
     * *分析要求*：从固定床反应器连续稳态运行条件、PEM 电解槽启停工况寿命衰减规律以及设备年利用小时数对固定资产投资（CAPEX）年金摊销的影响进行定量阐述。
  2. **问题 2（清洁电力临界替代率推导）**：若光伏电力与自备煤电实行混合供给，基于 LCA 核算模型，光伏清洁电力的供应比例 $x$ 至少达到多少百分比时，甲醇产品的全生命周期净碳足迹（$\text{GWP}_{\text{net}}$）才能低于传统煤制甲醇基准线（$+2,600.0\text{ kg CO}_2\text{e/t}$）？
* **定量推导提示与数值自检**：
  * 固定床反应器年设计满负荷运行需达到 $8,000\text{ h}$。若完全采用未配储能的离网分布式光伏，设备年利用率骤降至 $15.0\%$，单位产品设备折旧摊销成本上升至原先的 $6.67\text{ 倍}$；
  * 设绿电占比为 $x \in [0, 1]$，综合用电碳排放因子为 $EF(x) = 0.04x + 0.75(1-x) = 0.75 - 0.71x\text{ (kg CO}_2\text{e/kWh)}$。
  * 吨甲醇总用电量按 $10,826.0\text{ kWh}$ 核算，计入原料二氧化碳固定信用（$-1,423.0\text{ kg}$）及副产纯氧与基础设施折算（$+95.0 - 95.0 = 0.0\text{ kg}$），满足：
    $$
    \text{GWP}_{\text{net}}(x) = 10,826.0 \times (0.75 - 0.71x) - 1,423.0 \le 2,600.0
    $$
  * 解得最低临界绿电消纳比例为 **$x \ge 53.37\%$**（约为 $53.4\%$）。



## 三、 四大核心编程与仿真任务（`code_implementation/`）

进入 `code_implementation/` 目录，依照代码框架中的 `# TODO` 提示逐项完成以下四个仿真任务：

### 任务 1：MFA 反应-循环流非线性联立求解与质量守恒检验

* **执行脚本**：`code_implementation/task1_mfa_recycle_solver.py`
* **实训要求**：
  1. 依据 `data_cohort/mfa_reaction_recycle_balance.csv` 数据，建立包含新鲜气体进料、固定床催化反应器（单程转化率 $25.0\%$）、高压气液分离器与循环气分流器（分流比 $99.0\%$ 循环 / $1.0\%$ 驰放）的质量守恒方程；
  2. 求解并输出循环气流量（$4,640.0\text{ kg/t}$）、循环比（质量比 $2.86:1$，摩尔比 $3.8:1$）及系统总体碳转化利用率（验证是否严格等于 $96.0\%$）；
  3. 执行 C、H、O 三元素质量守恒校验，确保相对计算误差 $< 0.01\%$；
  4. 完成 10 万吨/年工程级通量放大核算，输出年需捕集 $\text{CO}_2$、电解绿氢、新鲜脱盐水、副产纯氧及全厂综合用电量。

### 任务 2：基于真实法规条文的政策量化规制引擎构建

* **执行脚本**：`code_implementation/task2_policy_vibe_engine.py`
* **实训要求**：
  1. 研读 `data_cohort/policy_clauses_pack.md` 中的四张政策卡片（欧盟 RED III 准入与溢价、中国碳市场阶梯奖惩与两高一票否决、工业取水定额累进水资源税、次生大气污染物环保税与清洁生产底线）；
  2. 借助 AI 编程辅助工具（如 Cursor / GitHub Copilot / Claude等），编写 Prompt 生成 `evaluate_policy_compliance()` 函数；
  3. 在脚本头部保留完整使用的 Prompt 文本，执行脚本内建的单元测试，验证三大典型工况的判定标签、补贴额度与调节费用是否与基准表严格吻合。

### 任务 3：MFA-LCA-TEA-Policy 多目标寻优与帕累托前沿求解

* **执行脚本**：`code_implementation/task3_pareto_frontier_decision.py`
* **实训要求**：
  1. 耦合任务 1 的 MFA 物料模型、LCA 净碳足迹模型、TEA 成本模型及任务 2 的政策量化算子；
  2. 以绿电消纳比例 $f_{\text{green}} \in [0.0, 1.0]$ 与循环回路分流比 $r_{\text{purge}} \in [0.004, 0.045]$ 为二维工程调控决策变量；
  3. 针对两个最小化目标（$\min \text{LCOM}_{\text{adjusted}}$ 与 $\min \text{GWP}_{\text{net}}$），遍历计算 3,000 组规划工况，运用非支配排序剔除被支配解与一票否决方案，提取有效帕累托前沿；
  4. 运用目标空间归一化欧氏距离最小化准则，自动标定帕累托拐点（Knee Point，锚点 B），并提取成本极小锚点 A 与深度脱碳极限锚点 C；
  5. 自动输出 300 DPI 矢量决策图表至 `figures_output/fig2_pareto_decision_frontier.png`。

### 任务 4：园区级工艺物质与能量流向图生成

* **执行脚本**：`code_implementation/task4_process_sankey_flow.py`
* **实训要求**：

  1. 提取帕累托拐点（锚点 B）的 10 万吨/年工程规划通量数据；
  2. 编写可视化绘图程序，清晰表达碳捕集、绿电制氢、催化合成、双塔精馏各工段的物料通量与综合电耗分布；
