# **# Title of Dataset**

***Global-scale raw data sets on production, trade and consumption of phosphorus-containing products***

**We submitted a total of ten datasets including (1) Phosphate rock origin data; (2) Country-level raw data on agricultural production and P calculations; (3) Country-level origin data on agricultural trade and P calculations; (4) Original aquaculture product data (national-level production and trade); (5) Original data on live animal products (national-level production and trade); (6) Original timber data (national-level production and trade); (7) Global and national level CPF application and trade data; (8) Global land use data; (9) Other datasets; (10) Calculation code based on python.**

In this study, the data can be categorized into two types: activity data and coefficient data. The activity data were collected from an official (governmental) statistical database, and the coefficient data were obtained from published literature. Type of data submitted is social activity data.

According to studies on anthropogenic P cycling, the FAOSTAT database (Food and Agriculture Organization, FAO) despite being incomplete, provides the most comprehensive agricultural product (exchange) data currently available for depicting global P flow scenarios. We obtained production and trade quantities for 460 agricultural products from FAOSTAT’s agriculture production and trade modules ([https://www.fao.org/faostat/zh/#data](https://www.fao.org/faostat/zh/#data), accessed December 2024). Additionally, FAOSTAT’s trade module provides total import and export data for crops and livestock products in each FAO country/region (n = 245) between 1961 and 2022, along with networks of bilateral trade relationships. The trade data used in this study excludes food aid and does not fully account for re-exported goods, as these are generally reported as negligible.

Phosphate rock reserves and mining data were sourced from the US Geological Survey (USGS, [https://www.usgs.gov/centers/national-minerals-information-center/rare-earths-statistics-and-information](https://www.usgs.gov/centers/national-minerals-information-center/rare-earths-statistics-and-information)). Mineral phosphate fertilizer usage data was obtained from FAOSTAT, while production data for non-fertilizer products was derived from their relative proportion in chemical fertilizer production. Mineral phosphate fertilizer trade data (including MAP, DAP, TSP, phosphoric acid, and phosphate rock) was obtained from The United Nations Comtrade database ([https://comtradeplus.un.org/TradeFlow](https://comtradeplus.un.org/TradeFlow)).

We also compared annual P flows in globally traded crops with the P content in global crop production and domestic mineral phosphate fertilizer usage in various countries. This data was sourced from FAOSTAT’s “Production” module (see FAOSTAT). Data on arable land and permanent crop areas was also obtained from FAOSTAT’s “Inputs” module (2022 data).

Finally, data from published literature are also used for complementing and comparison to check coefficients. We selected literature based on the following criteria: (1) Studies based on observation data in the global are selected in priority; (2) Studies with the methodology scientifically described are included in priority; (3) Studies published in highly-cited journals are included in priority. (4) Studies conducted by well-known research institutions were included as a priority.

# **## Description of the data and file structure**

**Data set 1. Phosphate rock origin data**

The dataset consists of 3 data files and 10 data tables: 1. Phosphate rock -trade - national level (WTO,1988-2023); 2. Phosphate rock (P2O5) production data-national level (USGS,1998-2022); 3. Phosphate rock reserve base-national level (2023).

**Data set 2. Country-level raw data on agricultural production and P calculations;**

The dataset consists of 3 data files and 64 data tables: 1. Raw data on agricultural production (1961-2022); 2. Agricultural products_P_result_national level(1961-2022); 3. Calculation of P for all agricultural products (1921-2022).

**Data set 3. Country-level origin data on agricultural trade and P calculations;**

The dataset consists of 4 data files and 126 data tables: 1. Country-level data on agricultural exports; 2. Country-level data on agricultural imports; 3. Calculated data on P in agricultural exports at the national level; 4. Calculated data on P in agricultural imports at the national level.

**Data set 4. Original aquaculture product data (national-level production and trade);**

The dataset consists of 8 data tables: aquaculture products.

**Data set 5. Original data on live animal products (national-level production and trade);**

The dataset consists of 2 data files and 36 data tables: 1. Production and stock; 2. Trade.

**Data set 6. Original timber data (national-level production and trade);**

The dataset consists of 10 data tables: wood.

**Data set 7. Global and national level Chemical phosphate fertilizer application and trade data;**

The dataset consists of 13 data tables: Chemical phosphate fertilizer.

**Data set 8. Global land use data;**

The dataset consists of 4 data tables: land use.

**Data set 9. Other datasets;**

The dataset consists of 2 data tables: 1. Global country-level population data; 2. Global national level food phosphorus supply data.

**Data set 10. Calculation code based on python.**

The dataset includes all the python code used for phosphorus flow calculations.
