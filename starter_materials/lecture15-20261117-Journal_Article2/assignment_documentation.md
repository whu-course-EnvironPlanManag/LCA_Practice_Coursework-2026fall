## 三、 实训核心任务与随堂通关节点

### 任务 1：数据清洗与农田种植子系统（ACS）类复现

1. 读取农产品纯磷产出表与含磷率字典，提取 1961–2022 年纯磷产出时间序列；
2. 参考 `ACSPModel` 编写农田种植系统计算类，输入施肥量、有机肥量、大气沉降与流失系数，计算作物吸收量、留存量与流失量；
3. **通关要求**：控制台正确输出 2022 年各流向数值。

### 任务 2：全系统闭环守恒自检与桑基图生成

1. 拓展模型类，将磷矿开采（PMS）、磷化工（CIS）、畜禽养殖（LBS）与居民消费（RCS）纳入计算；
2. 运行质量守恒自检，确保全系统相对误差严格小于 $10^{-4}$：

$$
\text{相对误差} = \frac{|\sum \text{输入流} - \sum \text{输出流} - \text{存量变化量}|}{\sum \text{输入流} + 10^{-6}}
$$

3. 使用 Plotly 生成 2022 年全流程磷物质流交互式桑基图并导出 HTML；
4. **通关要求**：控制台输出守恒断言通过信息，浏览器可正常交互浏览桑基图。

### 任务 3：2050 年“3R”情景模拟与交叉敏感性回归

1. 结合人口预测数据外推 2050 年常规基准情景（BAU）；
2. 设定“3R”参数：化肥减施 20%（Reduce）、粪便堆肥利用率提高至 75%（Replace）、污水鸟粪石回收率提高至 60%（Recycle）；
3. 运行交叉敏感性回归，检验政策变量对总磷流失或 PUE 的影响，输出标准化敏感性系数、显著性 $p$ 值与交互类型；
4. **通关要求**：控制台输出 2050 年情景对比数据及多元回归统计表。

## 四、 核心复现技术规范

### 4.1 数据读取与单位转换

* **列名规整**：工作表 `product_P_result (tons)` 表头混合文本与年份，读取后统一规整为整型年份列：
  ```python
  df_prod = pd.read_excel(filepath, sheet_name="product_P_result (tons)")
  df_prod.columns = [int(c) if str(c).isdigit() else c for c in df_prod.columns]
  ```
* **单位一致**：原始数据单位为吨（tons），全系统物质流核算与绘图推荐统一折算为千吨（kt P）或百万吨（Mt P）。

### 4.2 质量守恒自检断言

在模型类中嵌入断言检查，相对误差达到或超过 $10^{-4}$ 时主动报错：

```python
def verify_mass_balance(self, tolerance=1e-4):
    total_in = self.flows['Total_Input']
    total_out = self.flows['Total_Output']
    stock_delta = self.flows['Soil_Legacy_P']
    rel_err = abs(total_in - (total_out + stock_delta)) / (total_in + 1e-6)
    assert rel_err < tolerance, f"质量守恒未通过，相对误差: {rel_err:.6e}"
    return True
```

### 4.3 Plotly 桑基图节点映射

Plotly 的 `source` 与 `target` 严格要求为从 0 开始的非负整数列表，须先构建节点名称与索引的映射字典：

```python
nodes = ["Phosphate_Rock", "Chemical_Industry", "Cropland", "Crop_Harvest", "Waterbody", "Soil_Legacy_P"]
node_map = {name: idx for idx, name in enumerate(nodes)}
sources = [node_map["Phosphate_Rock"], node_map["Chemical_Industry"], node_map["Cropland"], node_map["Cropland"]]
targets = [node_map["Chemical_Industry"], node_map["Cropland"], node_map["Crop_Harvest"], node_map["Waterbody"]]
```

### 4.4 交叉敏感性回归与交互项判定

调用 `有交叉项.py` 时，自变量须先做均值中心化以降低多重共线性，再构造乘积项并做 Z-score 标准化：

```python
X1_c = data[var1] - data[var1].mean()
X2_c = data[var2] - data[var2].mean()
data[f"{var1}*{var2}"] = X1_c * X2_c
```

* **效应判定准则**：在回归系数显著（$p < 0.05$）前提下，若标准化交互系数 $> 0$ 判定为“协同增强”，$< 0$ 判定为“拮抗削弱”；$p \ge 0.05$ 判定为“无显著交互作用”。

## 五、 论文关键指标复现基准

以下为 Liu et al. (2026) 原文核心量化数据，供对照核验计算结果：

### 5.1 历史代谢与现状基准（图 1 与图 3）

* **历史累计输入**：1961–2022 年全球磷矿开采进入社会系统的纯磷总量约为 $1,153\text{ Mt P}$；
* **农田化肥增长**：矿物磷肥施用量由 1961 年约 $4.9\text{ Mt P}$ 增至 2022 年约 $20.5\text{ Mt P}$；
* **2022 年现状特征**：
  * 农田系统（ACS）化肥输入占总磷输入 64% 以上；
  * 畜禽养殖系统（LBS）整体磷利用效率（PUE）历史平均约 23%，为流失主要来源；
  * 农田土壤累积（Legacy P）与地表水流失（SWS）为主要环境汇。

### 5.2 2050 年情景杠杆效应基准（图 4A，相对 2050 BAU）

* **畜禽粪便循环利用（S4.3）**：
  * 原生磷矿开采需求（NPR）削减 **-22.1%**（精确模拟值 -22.15%）；
  * 农田矿物化肥投入需求（CFR）削减约 **-76.9%**；
  * 系统综合环境损失削减约 **-77%**；
* **饲料转化效率提升（S2.3）**：
  * 工业饲料需求（IFD）降低约 **-26%**，饲料粮需求（FGD）降低约 **-35%**；
  * 原生磷矿开采需求（NPR）降低约 **-17%**；
  * 种植业 PUE 提高约 18%，养殖业 PUE 提高约 36%；
* **全链条综合管理情景（S5）**：
  * 原生磷矿开采需求（NPR）削减 **-97%**；
  * 社会系统向自然水体与土壤的环境流失总量削减 **33%~98%**。

### 5.3 国家尺度达标分异基准（图 4B）

* **单措施优化**：35 个重点国家中仅 8 国（美、法、中、阿、巴、澳、加、德）可实现农田 PUE 达 70%；
* **全措施叠加**：达标 70% 的国家增至 17 个，仍有 18 个国家（如印度、巴基斯坦、越南、孟加拉国等）无法达标。

### 5.4 交叉敏感性回归基准（表 S11/S12）

* **拟合优度**：多元线性回归拟合优度 $R^2 > 0.85$；
* **关键交互项**：重点检验种植端节肥（S2.2）与养殖端粪污还田（S4.3）在总磷削减上的协同显著性（$p < 0.05$ 且 $\beta_{12} > 0$）。
